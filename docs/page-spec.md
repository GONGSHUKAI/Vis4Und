# 专题页规范

每个专题一页，帮读者把一块预备知识补起来。读者做机器人学习（VLA 微调、仿真评测）研究，熟悉深度学习和 PyTorch，但这一块不一定懂。

## 原则

- **简洁**：每一段都在讲一个具体概念、公式或数字。不写开场白、过渡句、总结段，不写「值得注意的是」「简单来说」「总之」这类话。能用一张图说清就不用三段话。
- **体系清楚**：页内按依赖顺序排，后面用到的概念前面已经定义过。别的页讲过的概念直接链过去，不重讲。
- **可视化优先**：每个核心概念配一个能交互的图（拖动、滑块、逐步播放），图要演示机制本身：同一个对象一步步被变换，而不是一排方框按顺序亮起。全页至少 5 个这样的图。
- **数学完整**：凡是有推导，先给记号表（符号 / 含义 / 形状或单位），再分步推导，每步一句话加一个公式，不跳关键步。公式用 LaTeX：行内 `$...$`，独立 `$$...$$`。
- **准确**：论文名、年份、arXiv 号、数字都要核对过；近年进展用网络搜索确认（今天是 2026-11 下旬），写明「截至 2026-11」。拿不准的不写。
- **读者没列全或列错的，帮他补上**，但补的内容同样要短。

## 页面结构

照 `docs/template.html`：

1. 首屏：kicker 写 `(<方向号>) <方向名> · (<专题号>)`，h1 是专题名，lede 一两句，「读完能回答」3–5 个问题。
2. 若干节 `<section id="...">`，每节一个 `<h2>`。目录由脚本从 h2 自动生成（`data-toc` 可以给一个更短的目录名）。
3. 倒数第二节「自测」：5–8 道 `details.q`，答案两三句。
4. 最后一节「延伸阅读」：`ol.refs`，论文写作者、标题、会议/年份、arXiv 链接；代码仓库给 GitHub 链接。

## 组件（全在 `assets/v4u.css` 里）

| 组件 | 用法 |
| --- | --- |
| `p.def` | 一句话定义，开头 `<b>术语</b>` |
| `figure.viz` | 可视化：`.viz-h`（标题 + 单位）、`.viz-stage`（canvas/svg）、`.viz-ctrl`（控件）、`.viz-read`（数值读数，每项一个 `<span>`）、`ul.chips`（图例，放图下面） |
| `table.notation` | 记号表 |
| `ol.derive` | 分步推导 |
| `.eq` | 单独一个重要公式 |
| `.note` / `.note.pit` | 补充 / 易错，开头 `<b>标题</b>` |
| `.tbl` | 对照表，数字列 `td.num` |
| `.seg` + `V4U.seg` | 分段按钮切换 |

JS 工具（`assets/v4u.js`，页面脚本写在 `V4U.ready(() => { ... })` 里）：

- `V4U.canvas(cv, height, draw)`：处理高清屏和缩放，主题切换时自动重画。
- `V4U.orbit3d(cv, opts, draw)`：轻量 3D 视图（z 轴朝上，可拖动旋转），给 `P.project / line / point / poly / text / frame`。
- `V4U.css('--c1')`：取颜色 token，canvas 画图一律用它，保证深浅两套主题都对。
- `V4U.drag`、`V4U.seg`、`V4U.loop`（只在可见时跑动画，尊重减弱动效设置）、`V4U.tex`、`V4U.fmt`。

## 设计

- 只用共享样式里的字体和颜色 token，不写颜色字面量。分类色依次用 `--c1` … `--c6`，配套浅色 `--c1s` …；坐标轴 x/y/z 用 `--bad / --ok / --c1`（红绿蓝）。
- 图里不放小字说明，说明写在图下的 `figcaption` 或图例里；图里的标签只标真实数值或对象名。
- 不画流水线式「方框 + 箭头」流程图。
- 每个可视化默认就处于有意义的状态，页面截图里就能看懂；动画由按钮启动。
- 宽度 390px 的手机上可用：不能横向滚动，宽表格和宽图放在自带横向滚动的容器里。
- 不引外部图片。脚本只从 jsdelivr / cdnjs 引，钉死版本号；能自己画的不引库。

## 流程

```bash
python3 tools/build.py --page <slug>      # 填入 head / 导航 / 页脚标记块，只动这一页
python3 tools/shot.py pages/<slug>/ --full   # 截桌面 / 手机 × 深 / 浅四张图
python3 tools/build.py                    # 全站：首页、README 列表、断链检查
```

`shot.py` 会报告控制台错误、KaTeX 解析错误和横向溢出，三者都要清零。
