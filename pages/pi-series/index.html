π 系列 VLA

Physical Intelligence 的 π 系列把预训练视觉语言模型和 flow matching 动作专家接在一起。从 π0、π0-FAST、π0.5、知识隔离（KI）、π*0.6 到 π0.7，每一代只解决上一代最卡脖子的一个问题：能做高频连续控制、训得快、开放世界泛化、不破坏 VLM 语义、用真机经验做 RL、多模态引导与零样本组合。

一代解决一个问题

整条技术主线按顺序叠加上去：π0（用 flow matching 实现 50 Hz 连续灵巧控制）→ π0-FAST（用频域压缩让自回归训练提速约 5×）→ π0.5（异构共训、离散预训练加连续后训练、同模型分层推理，解决开放世界泛化）→ KI（对 flow 损失到主干加 stop-gradient，保住 VLM 语义）→ π0.6 / π*0.6（换 Gemma 3 4B 底座，用优势条件化 RECAP 从真机经验学 RL）→ π0.7（加多模态上下文条件化与随机丢弃，涌现零样本组合泛化）。

与 RT-2 / OpenVLA 的路线差异

RT-2 与 OpenVLA 把机器人动作逐维分桶后塞进语言词表，让 VLM 自回归逐 token 吐出单步动作；π 系列给 VLM 外挂一个专门的连续动作生成器，离散 token（FAST）在最终形态里退居训练加速与表征保护的角色，推理始终靠 flow matching 一次生成整段动作块。

Flow matching 怎样生成动作块

条件 flow matching训练神经网络预测速度场 $\mathbf{v}_\theta(\mathbf{A}_t^\tau, o_t, \tau)$，使从标准高斯采样的噪声块沿常微分方程流向条件动作分布 $p(\mathbf{A}_t\mid o_t)$。

记号（全页通用）
符号含义形状 / 范围
$\mathbf{A}_t=[\mathbf{a}_t,\dots,\mathbf{a}_{t+H-1}]$时刻 $t$ 起的连续动作块，$H$ 为块长，$D$ 为动作维数$H\times D$（π0 默认 $50\times 18$ 或 $50\times 32$）
$o_t=(I_t^{1..n},\,\ell,\,\mathbf{q}_t)$当前观测：多路图像、语言指令 $\ell$、本体状态 $\mathbf{q}_t$图像序列 + 文本 + $\mathbb{R}^{D_q}$
$\tau$flow 时间步；$\tau=0$ 为纯噪声，$\tau=1$ 为干净动作标量，$\tau\in[0,1]$
$\boldsymbol{\varepsilon}$起点标准高斯噪声，$\boldsymbol{\varepsilon}\sim\mathcal{N}(\mathbf{0},\mathbf{I})$$H\times D$
$\mathbf{A}_t^\tau$时刻 $\tau$ 的插值含噪动作块$H\times D$
$\mathbf{u}(\mathbf{A}_t^\tau\mid\mathbf{A}_t)$给定真实动作块 $\mathbf{A}_t$ 时的条件速度目标$H\times D$
$\mathbf{v}_\theta(\mathbf{A}_t^\tau, o_t, \tau)$动作专家预测的速度场$H\times D$
$K,\ \delta$Euler 积分步数与步长，$\delta=1/K$整数（默认 $K=10$），标量（$0.1$）

推导

  1. 在噪声 $\boldsymbol{\varepsilon}$ 与目标动作块 $\mathbf{A}_t$ 之间构造线性插值路径（rectified / optimal-transport 条件流）：

    $$\mathbf{A}_t^\tau = \tau\,\mathbf{A}_t + (1-\tau)\,\boldsymbol{\varepsilon},\qquad \mathbf{A}_t^0=\boldsymbol{\varepsilon},\ \mathbf{A}_t^1=\mathbf{A}_t$$

  2. 对 $\tau$ 求导，得到沿这条直线匀速移动所需的条件速度场：

    $$\mathbf{u}(\mathbf{A}_t^\tau\mid\mathbf{A}_t)=\frac{d\mathbf{A}_t^\tau}{d\tau}=\mathbf{A}_t-\boldsymbol{\varepsilon}$$

  3. 用均方误差训练动作专家 $\mathbf{v}_\theta$ 回归该条件速度（由条件 flow matching 定理，该目标与匹配真实边际速度场的梯度完全一致）：

    $$\mathcal{L}_{\text{FM}}(\theta)=\mathbb{E}_{p(\mathbf{A}_t,o_t),\,\mathcal{N}(\boldsymbol{\varepsilon};\mathbf{0},\mathbf{I}),\,p(\tau)}\!\left[\left\|\mathbf{v}_\theta(\mathbf{A}_t^\tau, o_t, \tau)-(\mathbf{A}_t-\boldsymbol{\varepsilon})\right\|_2^2\right]$$

  4. 给定同一含噪位置 $\mathbf{x}=\mathbf{A}_t^\tau$，最小二乘的最优速度场是条件期望 $\mathbf{v}^\star(\mathbf{x},o_t,\tau)=\mathbb{E}[\mathbf{A}_t-\boldsymbol{\varepsilon}\mid \mathbf{A}_t^\tau=\mathbf{x}, o_t]$。推理时从 $\mathbf{A}_t^0\sim\mathcal{N}(\mathbf{0},\mathbf{I})$ 出发，做 $K=10$ 步前向 Euler 积分（$\delta=0.1$）：

    $$\mathbf{A}_t^{\tau+\delta}=\mathbf{A}_t^\tau+\delta\,\mathbf{v}_\theta(\mathbf{A}_t^\tau, o_t, \tau),\qquad \tau=0,\ \delta,\ \dots,\ 1-\delta$$

  5. 时间步采样分布 $p(\tau)$ 不取均匀分布，而是把权重偏向低 $\tau$（高噪声）端，并在 $s=0.999$ 处截断，避开 $\tau=1$ 的退化点：

    $$p(\tau)=\operatorname{Beta}\!\left(\frac{s-\tau}{s};\,1.5,\,1\right),\quad s=0.999\quad\Longleftrightarrow\quad \tau=0.999\,(1-u),\ u\sim\operatorname{Beta}(1.5,1)$$

为什么不用直接 MSE 回归：当同一观测 $o_t$ 下存在多条可行轨迹（例如绕过障碍物的左路与右路），$\min_f\mathbb{E}[\|f(o_t)-\mathbf{A}_t\|^2]$ 的唯一最优解是条件均值 $\mathbb{E}[\mathbf{A}_t\mid o_t]$，恰好落在两峰之间的无效甚至碰撞区域。Flow matching 从不同高斯起点 $\boldsymbol{\varepsilon}$ 出发，在 $\tau$ 较小时由边际速度场分叉，把粒子各自送入不同的真实动作峰；这也是为什么 $p(\tau)$ 要向高噪声端倾斜——高噪声阶段决定模态分叉与轨迹轮廓，低噪声阶段只需局部微调。

约定陷阱：论文符号与 openpi 代码时间方向相反

π0 论文（arXiv:2410.24164）同时写了 $\mathbf{A}_t^\tau=\tau\mathbf{A}_t+(1-\tau)\boldsymbol{\varepsilon}$ 和 $\mathbf{u}=\boldsymbol{\varepsilon}-\mathbf{A}_t$，后者的符号与前者对 $\tau$ 求导的方向相反；本页全篇统一采用 $\tau=0$ 为噪声、$\tau=1$ 为动作、$\mathbf{u}=\mathbf{A}_t-\boldsymbol{\varepsilon}$、从 $0$ 积到 $1$ 的自洽约定。openpi 代码（src/openpi/models/pi0.py）则采用相反但同样自洽的扩散风格约定：time=1 是噪声、time=0 是干净动作，x_t = time * noise + (1 - time) * actions，u_t = noise - actions，采样 time = Beta(1.5, 1) * 0.999 + 0.001（同样偏向高噪声的 time→1 端），推理时以负步长 dt = -1 / K 从 1 积到 0。做代换 $t=1-\tau$ 后，两套约定数学上完全等价。

π0 架构与分块因果注意力

  • VLM 主干：PaliGemma 3B，由 400M SigLIP 视觉编码器与 2.6B Gemma 语言模型组成（width=2048，depth=18，mlp_dim=16384，head_dim=256，num_heads=8，num_kv_heads=1 的 MQA）。
  • 动作专家：约 300M 参数、从零初始化的缩小版 Gemma（width=1024，mlp_dim=4096，保持相同的 depth=18 与注意力头结构），全模型共约 3.3B 参数。
  • 双专家交互：图像 patch 与语言 token 走 VLM 权重，本体状态与含噪动作 token 走动作专家权重；两套权重拥有独立的 Q/K/V 投影、FFN 与归一化层（类似 2 专家 Mixture-of-Transformers），只在每一层的 self-attention 中把序列拼在一起计算注意力。
  • 三块分块因果掩码与前缀 KV 缓存：Block 1（图像 + 语言）块内双向、不可见后续块；Block 2（单个状态 token $\mathbf{q}_t$）可见 Block 1 和自身、不可见动作；Block 3（$H=50$ 个含噪动作 token）块内双向、可见前两块。10 步 Euler 去噪过程中 Block 1 与 Block 2 不变，只需计算一次并缓存其 KV，每步去噪仅用 300M 动作专家重算 50 个动作 token。
  • 数据与两阶段训练：总数据超过 10,000 小时，含自有 7 种机器人构型、68 个任务、903M 时间步（106M 单臂 + 797M 双臂），以及占比 9.1% 的开源数据（OXE、Bridge v2、DROID）。预训练混入全量数据（含错误恢复行为）学广度，后训练用 5–100+ 小时高质量单任务数据打磨精度。

跨本体异构数据训练

π 系列不做跨本体的动作语义统一（不强行转换到统一末端空间，也不做运动学重定向），只做张量形状对齐，其余交给模型根据视觉和状态分布自行学会。

  • 保留原生关节动作：各平台直接输出自身关节目标 + 夹爪（加底盘速度或躯干升降）。π0 论文覆盖的维度包括：单臂 UR5e（7 维）、Franka（8 维）、双臂 UR5e / Trossen / ARX / AgileX（14 维）、非完整约束移动双臂（状态 14 / 动作 16 维）、完整约束移动双臂（状态 14 / 动作 17 维），最大 18 维（双 6-DoF 臂 + 2 夹爪 + 移动底盘 + 躯干）。
  • 补零与相机掩码，无显式本体 ID：低维机器人向量零填充至统一维度（π0 论文为 18 维，openpi 代码默认 32 维）；少于 3 路相机的平台将缺失相机槽位 mask 掉；输入不加本体 ID token，模型通过画面里的机械臂外观和状态分布隐式识别本体。
  • 开源数据原样混入：占混合 9.1% 的 OXE / Bridge v2 / DROID 多为 2–15 Hz 低频且常用末端增量动作，论文直接补零混入训练，未做向关节空间转换或重采样；具体各数据集动作定义见 常见数据集与策略动作对照。
  • π0.5 的改进：同一条轨迹可同时以关节目标与末端位姿两种参数化训练，通过文本 prompt 中的 << control_mode >> joint << control_mode >> 与 << control_mode >> end effector << control_mode >> 显式切换；归一化从 z-score 改用 1% / 99% 分位数映射到 $[-1,1]$，具体公式见 动作归一化。

FAST：基于频域压缩的动作 tokenizer

FAST（Frequency-space Action Sequence Tokenization，Pertsch et al., RSS 2025）先对连续动作块做分位数归一化与离散余弦变换（DCT），再量化、低频优先交织展平并用 BPE 压缩，把高度冗余的高频轨迹压成短而信息密集的离散 token 序列。

为什么朴素逐维逐步分桶在高频下学不动：逐维逐时间步分桶产生的 token 数为 $H\times D$（50 Hz 双臂 14 维即 700 个 token）。采样频率越高，相邻时间步的关节角越接近，每个 token 相对前缀的条件熵（边际信息量）趋近于 0。自回归模型只需学会「复制上一个 token」就能把交叉熵压到极低，陷入退化局部最优，在 20 Hz / 50 Hz 真机任务上几乎无法推进任务。

FAST 记号
符号含义形状 / 取值
$a_t^{(d)}$归一化到 $[-1,1]$ 后，第 $d$ 维在第 $t$ 步的动作$t\in\{0,\dots,H-1\}$，$d\in\{1,\dots,D\}$
$C_{k,d}$第 $d$ 维沿时间轴的正交 DCT-II 系数，$k$ 为频率下标$H\times D$，$k=0$ 为直流分量
$\gamma$量化缩放因子，控制重建精度与压缩率权衡标量，默认 $\gamma=10$
$\bar{C}_{k,d}$取整后的稀疏整数系数，$\bar{C}_{k,d}=\operatorname{round}(\gamma\,C_{k,d})$整数矩阵 $H\times D$
$V_{\text{BPE}}$BPE 词表大小整数，默认 $1024$

  1. 按数据集统计的 1% / 99% 分位数把每一维动作映到 $[-1,1]$。

  2. 对每个动作维 $d$ 沿时间轴做正交 DCT-II；平滑轨迹的能量集中在低频（小 $k$）：

    $$C_{k,d}=\alpha_k\sum_{t=0}^{H-1}a_t^{(d)}\cos\!\left(\frac{\pi}{H}\Big(t+\tfrac{1}{2}\Big)k\right),\qquad \alpha_0=\sqrt{\tfrac{1}{H}},\ \alpha_{k\ge1}=\sqrt{\tfrac{2}{H}}$$

  3. 乘以 $\gamma$ 后四舍五入，高频小幅系数成片归零：

    $$\bar{C}_{k,d}=\operatorname{round}(\gamma\,C_{k,d})$$

  4. 按频率优先（column-first）交织展平，让自回归解码先输出决定整体轮廓的低频分量：

    $$T=[\bar{C}_{0,1},\dots,\bar{C}_{0,D},\ \bar{C}_{1,1},\dots,\bar{C}_{1,D},\ \dots,\ \bar{C}_{H-1,D}]$$

  5. 在展平后的整数序列上执行词表 $V_{\text{BPE}}=1024$ 的 BPE 编码，无损压掉大段连续 0 与跨维共现模式；解码时逆向 BPE、除以 $\gamma$ 再做 IDCT-II 还原动作块。

本体状态怎样进入模型

π 系列对本体状态 $\mathbf{q}_t$ 有两种截然不同的接入方式：

  • 路线 A — 连续投影（π0）：将状态向量通过一个线性层 state_proj 映成单个连续 token，放入 Block 2，走动作专家权重。
  • 路线 B — 256 桶离散文本（π0-FAST、π0.5、π0.6）：按 1% / 99% 分位数归一化到 $[-1,1]$ 后均匀切成 $B=256$ 个桶，得到 $0\dots255$ 的整数编号，直接拼成十进制字符串放进文本前缀（如 Task: fold shirt, State: 157 19 252 ...; Action:），走普通 SentencePiece 文本分词器进入 VLM 主干。注意借用词表尾部专用 token 的是 FAST 动作，状态不占专用 token。

为什么输入端分桶够用、输出端不行：本体状态是条件输入，约 0.4% 量程的量化误差几乎不影响策略判断；而输出端每一丝离散化误差都会直接进入执行器，且逐维逐步分桶在高频下会摧毁自回归训练信号。

文本分桶的五个缺点：（1）精度上限锁死在量程的 $1/256$；（2）丢失连续数值结构，字符串 100 与 101 的嵌入本身没有相邻几何关系，需依赖语言预训练的数字理解能力；（3）token 膨胀，18 维状态拆成十进制文本要占掉数十个前缀 token，而 π0 的连续投影只需 1 个 token；（4）超出 $[q_{01},q_{99}]$ 的离群状态被截到边界桶；（5）跨本体混训需按数据集分别保存归一化统计量。

两阶段训练与架构微调

$$\mathcal{L}_{\pi_{0.5}} = \mathcal{L}_{\text{CE}}(\text{text, bbox, FAST}) + \alpha\,\mathcal{L}_{\text{FM}}(\mathbf{v}_\theta)$$
  • 预训练（280k 步，$\alpha=0$）：不挂动作专家，整个模型是纯自回归 VLM，用统一交叉熵同时学网页问答、物体定位、高层子任务与 FAST 动作 token，收敛快且保住语言跟随。
  • 后训练（80k 步，$\alpha=10$）：接上随机初始化的 300M flow 动作专家，在目标任务数据上联合优化文本 + FAST 交叉熵与 10 倍权重的 flow matching 损失；推理时直接用 10 步 flow 输出 50 Hz 动作块，兼顾训练速度与推理延迟。
  • 为什么状态改放前缀：280k 步预训练期间没有动作专家，本体状态只能以 256 桶文本放进前缀；后训练保持同一格式，才能把预训练学到的「读状态」能力无缝继承下来。
  • adaRMSNorm 注入 $\tau$：π0 把时间步 $\tau$ 编码后与动作 token 拼接混合，π0.5 改为让 $\tau$ 经 MLP 映射后通过 adaRMSNorm 逐层调制动作专家的归一化层（仅作用于动作专家，不碰 VLM 主干）。

同模型两段式分层推理

$$\pi(\mathbf{A}_t,\hat{\ell}\mid o_t,\ell)=\underbrace{\pi(\mathbf{A}_t\mid o_t,\hat{\ell})}_{\text{低层 50 Hz flow（3 路相机）}}\;\underbrace{\pi(\hat{\ell}\mid o_t,\ell)}_{\text{高层低频自回归（4 路相机）}}$$

高层规划与低层执行共享同一套模型权重，性质接近 test-time chain-of-thought：高层用全部 4 路相机（双腕 + 前视 + 后视）以低频自回归吐出当下可执行的短子任务 $\hat{\ell}$（如把 clean the kitchen 拆成 pick up the plate），低层只看子任务 $\hat{\ell}$、不看总指令 $\ell$，用 3 路相机（双腕 + 前视）做 10 步 flow 去噪输出 50 Hz 动作块。

高层消融结论（固定同一个低层动作策略，只替换高层子任务来源）：（1）完整 π0.5（自己出 $\hat{\ell}$ 自己执行）得分最高，甚至高于人类专家实时观察下发子任务；（2）Implicit HL（训练含 HL 数据但推理不显式解码 $\hat{\ell}$）排第二，说明大部分收益来自 HL 共训，显式分层在其上再加一层增益；（3）训练去掉 HL 数据后性能明显下滑；（4）外接通用 GPT-4 当高层效果最差，说明高层规划必须在机器人数据上落地适配；（5）收益主要集中在长时序多步任务，短任务对高层不敏感。

知识隔离（Knowledge Insulation）

知识隔离（KI）由 Driess et al.（2025-05，arXiv:2505.23705）正式提出：在同一前向中联合训练离散动作与连续 flow 专家，但在 VLM 主干传给动作专家的接口上插入 stop-gradient，阻断连续动作头的反向梯度回流主干。

与 π0.5 的区别：π0.5 只做了注意力单向隔离（VLM token 不注意动作专家，FAST 与 flow 两条分支互不注意），但后训练阶段 flow matching 损失的梯度依然会经由共享注意力的 K/V 反向更新 VLM 主干。随机初始化的连续动作头在训练早期产生大且高方差的梯度，会破坏 VLM 预训练习得的语言与语义表征，这也是 π0.5 不得不先做 280k 步无专家预训练的原因。

KI 在 K/V 跨分支接口处加上 $\operatorname{sg}(\cdot)$ 后，VLM 主干权重 $\theta_{\text{VLM}}$ 只接收网页多模态、子任务文本与 FAST 离散动作的交叉熵梯度；动作专家 $\theta_{\text{act}}$ 读取 $\operatorname{sg}(K_{\text{VLM}}, V_{\text{VLM}})$ 并独自承担 $\mathcal{L}_{\text{FM}}$ 的梯度更新。结果是无需两阶段热身即可单阶段联合训练，收敛步数最多减少约 7.5×，同时保住语言指令跟随与 10 步 flow 的高速推理。后续的 openpi 开源 pi05_base、π0.6 / π*0.6 与 π0.7 均沿用了这一配方。

π0.6 与 π*0.6 / RECAP：用优势条件化做 RL

纯模仿学习的上限锁死在演示质量上，且部署时会出现分布偏移与复合误差。π0.6 将底座升级为 Gemma 3 4B + 860M flow 动作专家，保留分层推理、50 Hz 分块与知识隔离；π*0.6（Physical Intelligence，2025-11，arXiv:2511.14759）在此基础上引入 RECAP（RL with Experience and Corrections via Advantage-conditioned Policies），把真机自主经验与人工纠正直接编入训练闭环。

RECAP 三步迭代

  1. 数据收集：在真机运行当前策略，为每个 episode 标注成败；允许专家在线介入遥操作纠正（HG-DAgger 风格），纠正片段强制标记为正优势。
  2. 分布式价值函数：用 670M 小 VLM（Gemma 3 初始化）训练多任务价值函数 $V^{\pi_{\text{ref}}}(o_t)$，将回报离散到 201 个桶 做交叉熵回归（并混入网页数据防过拟合）。奖励定义为每步 $-1$、终局成功 $0$、终局失败 $-C_{\text{fail}}$：
    $$r_t=\begin{cases}0 & t=T\text{ 且成功}\\ -C_{\text{fail}} & t=T\text{ 且失败}\\ -1 & \text{其余每步}\end{cases}$$
    成功轨迹里 $V^{\pi_{\text{ref}}}(o_t)$ 就是期望的负剩余完成步数，天然同时奖励「做成功」和「做得快」。
  3. 优势条件化监督训练：后训练用 $N=50$ 的 $N$-step 优势（预训练取 $N=T$ 整条 Monte Carlo 回报，单次价值前向即可在线算完）：
    $$\hat{\mathcal{A}}^{\pi_{\text{ref}}}(o_t,\mathbf{a}_t)=\sum_{t'=t}^{t+N-1}r_{t'}+V^{\pi_{\text{ref}}}(o_{t+N})-V^{\pi_{\text{ref}}}(o_t)$$
    与任务阈值 $\epsilon_\ell$（预训练时按任务取值，使约 30% 的示教数据为正；要换速度的任务收紧到约 10% 为正）比较得到二值指示 $I_t=\mathbb{1}[\hat{\mathcal{A}}^{\pi_{\text{ref}}}(o_t,\mathbf{a}_t)>\epsilon_\ell]$，以文本 token Advantage: positive 或 Advantage: negative 插在子任务 $\hat{\ell}$ 之后、动作之前（仅条件化低层动作），在全部数据（好坏皆留）上做纯监督训练（离散 CE + flow matching），并以 30% 概率随机丢弃该 token 以同时学出无条件策略。

为什么条件化等价于策略改进（CFGRL 推导）

RECAP 记号
符号含义形状 / 类型
$\pi_{\text{ref}}(\mathbf{a}\mid o)$收集数据的参考策略（或历史数据混合分布）条件分布
$\mathcal{A}^{\pi_{\text{ref}}}(o,\mathbf{a})$优势函数（标量，与前文动作块 $\mathbf{A}_t$ 区分）标量
$\epsilon_\ell$任务 $\ell$ 的优势阈值（标量，与前文噪声 $\boldsymbol{\varepsilon}$ 区分）标量
$I$二值改进指示符，$I=\mathbb{1}[\mathcal{A}^{\pi_{\text{ref}}}(o,\mathbf{a})>\epsilon_\ell]$$\{\text{True},\text{False}\}$
$\beta$引导权重，控制向高优势区域倾斜的强度$\beta\ge0$（默认 $\beta=1$）

  1. 给定参考策略 $\pi_{\text{ref}}$ 与优势指标 $I$，按 CFGRL（Frans et al., 2025）定义倾斜后的目标策略，它把概率质量向满足 $I=\text{True}$ 的动作集中，保证期望回报不降 $J(\hat{\pi}_\beta)\ge J(\pi_{\text{ref}})$：

    $$\hat{\pi}_\beta(\mathbf{a}\mid o)\propto \pi_{\text{ref}}(\mathbf{a}\mid o)\,p\big(I=\text{True}\mid \mathcal{A}^{\pi_{\text{ref}}}(o,\mathbf{a})\big)^\beta$$

  2. 当 $\beta=1$ 时，分子乘以常数 $1/p(I=\text{True}\mid o)$ 即得贝叶斯后验：

    $$\hat{\pi}_1(\mathbf{a}\mid o)=\frac{\pi_{\text{ref}}(\mathbf{a}\mid o)\,p(I=\text{True}\mid o,\mathbf{a})}{p(I=\text{True}\mid o)}=\pi_{\text{ref}}(\mathbf{a}\mid I=\text{True},\,o)$$

  3. 因此无需显式算对数似然或重要性权重，只需在全部数据上用标准监督损失拟合条件分布 $\pi_\theta(\mathbf{a}\mid I, o)$，推理时把条件钉在 Advantage: positive 就能直接从 $\hat{\pi}_1$ 采样。

  4. 当需要 $\beta>1$ 时，由于训练期 30% 丢弃了条件 token，同一模型同时学出了无条件速度场，可对 flow 速度场做 classifier-free guidance（RECAP 默认 $\beta=1$，必要时温和取 $\beta\in[1.5,2.5]$）：

    $$\tilde{\mathbf{v}}_\theta(\mathbf{A}_t^\tau, o_t, \tau)=\mathbf{v}_\theta(\text{uncond})+\beta\big(\mathbf{v}_\theta(\text{pos})-\mathbf{v}_\theta(\text{uncond})\big)$$
  • 为什么不用 PPO / AWR：Flow matching 模型没有解析可算的对数似然 $\log\pi_\theta(\mathbf{a}\mid o)$，无法直接套用 PPO 的重要性比值，且真机数据是批式离线的（论文实现的 PPO 基线必须把信任域压到 $\eta=0.01$ 才稳定，性能仍落后）；AWR（优势加权回归）本质是过滤式模仿，丢弃大量低权重样本，实测动作更慢、吞吐显著低于 RECAP。
  • 真机结果与局限：在叠衣、折纸箱、操作专业意式咖啡机等难任务上，RECAP 在最难的几项上把吞吐量（每小时成功次数）提升到 2 倍以上、失败率大约减半；除多样衣物叠放外，各任务成功率在 90% 以上；咖啡机任务连续稳定制作双份浓缩 13 小时；在定向消除叠衣失败模式的消融中，两轮自主 RL 把严格判据下成功率推到 97%。局限在于成败标注、人工介入与环境重置仍需人工，且为批式离线迭代而非全在线 RL。

自测

为什么 π0 不用直接 MSE 回归预测动作块，而要用 flow matching？

多峰动作分布下，MSE 回归的最优解是条件均值，会落到两个可行模态之间的无效或碰撞区域。Flow matching 从不同高斯噪声出发沿条件速度场分叉，能完整表达多峰连续分布。

为什么 π0 训练时时间步 $\tau$ 不均匀采样，而是用偏向高噪声端的 Beta 分布？

高噪声阶段决定样本流向哪个模态与整体动作轮廓，学习难度更高；低噪声阶段只需小幅修整。在论文约定（$\tau=0$ 噪声）下取 $\tau=0.999(1-u)$，在 openpi 代码（time=1 噪声）下取 time=0.999*u+0.001，其中 $u\sim\operatorname{Beta}(1.5,1)$，两者都是偏向高噪声端并避开无噪声端点。

π0 做 10 步 Euler 去噪，推理延迟为什么仍然远低于自回归的 π0-FAST？

因为 π0 的三块分块因果掩码让前缀（图像 + 语言）和状态在 10 步去噪中保持不变，只需前向一次并缓存 KV；10 步去噪只重算 300M 小动作专家的 50 个动作 token（RTX 4090 上约 100 ms）。π0-FAST 则需用完整 2B 主干逐个自回归解码 30–60 个 token（约 750 ms）。

为什么 50 Hz 高频控制下，朴素逐维逐步分桶会让自回归 VLA 学不动？

高频下相邻时间步动作几乎相同，每个 token 相对前缀的边际信息量趋近于 0，模型学会「复制上一个 token」就能把交叉熵压得很低，失去真实控制信号。FAST 用 DCT 去除时间冗余、量化清零高频再用 BPE 压缩（50 Hz 叠衣 13.2×），恢复了每个 token 的信息密度。

π0.5 里本体状态和动作同样是连续向量，为什么状态用 256 桶文本就够用，动作输出端不行？

状态是条件输入，约 0.4% 量程的量化误差几乎不影响决策，且 280k 步预训练阶段没有动作专家，文本格式能保证两阶段无缝衔接；动作输出端的量化误差会直接变成机械臂执行误差，且逐维逐步分桶在高频下无法自回归训练。

π0.5 的注意隔离和知识隔离（KI）论文有什么本质区别？

π0.5 只屏蔽了注意力（VLM 不看动作专家、FAST 与 flow 互不看），后训练时 flow 损失的梯度仍会沿共享注意力的 K/V 回流 VLM 主干。KI 在跨分支 K/V 接口显式加入 stop-gradient，使主干只吃离散 CE 梯度，从而免去两阶段热身并大幅缩短训练步数。

为什么 π*0.6 不用 PPO，而把 RL 写成优势条件化的监督训练？

Flow matching 模型没有解析可算的对数似然 $\log\pi_\theta(\mathbf{a}\mid o)$，难以直接做策略梯度或 PPO 重要性比值更新，且真机数据是批式离线的。由贝叶斯公式，当 $\beta=1$ 时改进策略 $\hat{\pi}_1(\mathbf{a}\mid o)$ 恰好等于条件分布 $\pi_{\text{ref}}(\mathbf{a}\mid I=\text{True},o)$，用全部数据监督训练后把条件固定为 Advantage: positive 即可采样改进策略。
