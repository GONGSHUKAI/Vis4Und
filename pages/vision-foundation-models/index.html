视觉基础模型

在进入 3D 重建和 VLA 策略之前，先理清 2D 视觉基础模型：DINO、CLIP / SigLIP、Grounding DINO、SAM 1–3 与 Grounded SAM、Depth Anything 各自吃什么输入、吐什么输出、靠什么监督训出来、名字撞车的几个模型究竟是什么关系，以及机器人系统里怎么挑、怎么拼。近年进展截至 2026-11。

总览：六类模型与名字辨析

机器人感知里常被一起提到的「视觉基础模型」分属五种不同的输出接口（表征、图文对齐、开放词表检测、可提示分割、单目深度），再加一套把检测和分割串起来的组合流程。

易错：名字撞车与组合关系

① 两个 DINO 毫不相干：自监督表征模型 DINO（self-distillation with no labels，Caron et al., ICCV 2021）用 ViT 学图像特征；目标检测器 DINO-DETR（DETR with Improved deNoising anchOr boxes，Zhang et al., ICLR 2023）是 DETR 架构的检测器，两者毫无继承关系。

② Grounding DINO 的骨干不是 DINO ViT：Grounding DINO 里的「DINO」指检测器 DINO-DETR。原文用的图像骨干是 Swin Transformer，文本编码器是 BERT。

③ 「Grounding SAM」正式名是 Grounded SAM，且不是单个模型：它是把 Grounding DINO（文本 → 框）和 SAM（框 → 掩码）拼起来的推理流程；视频版 Grounded-SAM-2 再接 SAM 2 跟踪。把「文本短语 → 图里所有实例的掩码与跟踪」做成单一模型的是 SAM 3（2025-11）。

ViT 基础：patch、分辨率与注意力代价

Vision Transformer（ViT，Dosovitskiy et al., ICLR 2021）把图像 $I\in\mathbb R^{H\times W\times 3}$ 切成 $N_p=(H/p)(W/p)$ 个不重叠的 $p\times p$ 图像块（patch），线性投射为 $d$ 维 token，拼上位置编码和可选的全局 [CLS] token 后送进标准 Transformer 编码器。

后面几乎所有视觉基础模型都用 ViT（或其层级变体 Swin / Hiera）作骨干，选型时看四个数字：

  • 特征图分辨率 $H_p\times W_p=(H/p)\times(W/p)$：每个 patch 只对应一个特征向量。$p=14$ 或 $16$ 意味着输出特征图比原图小 14–16 倍，小零件在低分辨率输入下可能不到一个 patch。
  • patch 14 vs 16：224×224 输入下，$p=16$ 得到 $14\times 14=196$ 个 patch token；$p=14$ 得到 $16\times 16=256$ 个 token。DINOv2、CLIP ViT-L/14、SigLIP-So400m、SAM 3 常用 $p=14$；ViT 原版、SAM 1、DINOv3 用 $p=16$。
  • 位置编码与变分辨率：学习式绝对位置编码（ViT、DINOv2、CLIP、SigLIP）在换输入尺寸时需对位置编码网格做双三次插值；2D 轴向 RoPE（DINOv3）按相对坐标旋转 query/key，可直接推到远高于训练尺寸的分辨率。
  • $O(N_p^2)$ 注意力代价：长宽同时翻倍，$N_p$ 变 4 倍，全局自注意力矩阵元素数 $N_p^2$ 变 16 倍。高分辨率骨干（如 SAM 1 在 1024×1024 下的 4,096 个 token）常把多数层换成局部窗口注意力，只保留少数全局注意力层，并配合 FlashAttention 降显存读写（见 FlashAttention）。

自监督特征：DINO → DINOv2 → DINOv3

DINO（Caron et al., ICCV 2021）用同一个架构的两个网络做无标签自蒸馏：学生 $g_{\theta_s}$ 梯度更新，教师 $g_{\theta_t}$ 是学生权重的指数滑动平均（EMA），训练学生从局部裁剪预测教师对全局裁剪的输出分布。

输入一张图做多裁剪（multi-crop）：2 张全局大图（如 $224^2$）和若干张局部小图（如 $96^2$）。教师只看全局视图，学生看全部视图，强迫网络学会「局部部件属于哪个整体」。教师权重按 $\theta_t\leftarrow\lambda_{\text{ema}}\theta_t+(1-\lambda_{\text{ema}})\theta_s$ 更新（$\lambda_{\text{ema}}$ 从 0.996 余弦升到 1），推理和训练时教师端截断梯度。

推导：中心化与锐化如何防塌缩

没有负样本的自蒸馏存在平凡解（塌缩）：无论输入什么图，学生和教师都输出同一个常向量，损失立刻归零。DINO 只在教师输出端加两步操作就稳住了训练：

  1. 学生和教师各自输出 $K$ 维 logits（原文 $K=65{,}536$），学生用温度 $\tau_s=0.1$ 做 softmax，教师先减中心 $\mathbf c$ 再用更低的温度 $\tau_t\in[0.04,0.07]$ 做 softmax：

    $$P_s(x)_k=\frac{\exp(g_{\theta_s}(x)_k/\tau_s)}{\sum_{j=1}^K \exp(g_{\theta_s}(x)_j/\tau_s)},\qquad P_t(x)_k=\frac{\exp\!\big((g_{\theta_t}(x)_k-c_k)/\tau_t\big)}{\sum_{j=1}^K \exp\!\big((g_{\theta_t}(x)_j-c_j)/\tau_t\big)}$$

  2. 跨视图最小化交叉熵（全局视图集合 $V_g$，全部视图集合 $V$）：

    $$\mathcal L_{\text{DINO}}=\sum_{x_g\in V_g}\sum_{\substack{x'\in V\\ x'\neq x_g}} H\big(P_t(x_g),\,P_s(x')\big),\qquad H(a,b)=-\sum_{k=1}^K a_k\log b_k$$

  3. 中心向量 $\mathbf c$ 追踪教师在一批样本上的平均输出（动量 $m_c=0.9$）：

    $$\mathbf c\leftarrow m_c\,\mathbf c+(1-m_c)\frac{1}{B}\sum_{i=1}^B g_{\theta_t}(x_i)$$

  4. 考察两种指标：单样本熵 $\overline{H(P_t)}=\frac{1}{B}\sum_i H(P_t(x_i))$ 衡量单张图的分布有多尖锐；批平均分布 $\bar P_t=\frac{1}{B}\sum_i P_t(x_i)$ 的熵 $H(\bar P_t)$ 衡量整批样本用到了多少不同原型。两者之差 $H(\bar P_t)-\overline{H(P_t)}$ 正好是样本编号与原型编号之间的互信息，塌缩时它归零：

    $$\begin{aligned}\text{只留中心化（}\tau_t\text{ 大）}&\Rightarrow P_t(x_i)\to\tfrac{1}{K}\mathbf{1}\quad(\overline{H}\to\log K\text{，均匀塌缩})\\ \text{只留锐化（去掉 }\mathbf c\text{）}&\Rightarrow P_t(x_i)\to\mathbf{e}_{k^*}\quad(H(\bar P_t)\to 0\text{，单模塌缩})\end{aligned}$$

    中心化把批均值拉向零，阻止某一维垄断全部样本（保 $H(\bar P_t)$ 高）；锐化用低 $\tau_t$ 压低单样本熵（保 $\overline{H(P_t)}$ 低）。两股力互相拉扯，逼出有区分度的聚类原型。

DINO 训练出的 ViT 出现涌现现象：最后一层 [CLS] token 对各 patch 的自注意力头无需任何掩码标注就能勾出前景物体轮廓。

DINOv2、Registers 与 DINOv3

  • DINOv2（Oquab et al., TMLR 2024）：用自动去重 + 检索管线构造 1.42 亿张图的数据集 LVD-142M。损失上把图像级 DINO 和 patch 级掩码预测 iBOT（Zhou et al., ICLR 2022，随机掩码部分 patch，学生从上下文预测教师对应 patch 的原型分布）合在一起，但拆开投影头；用 3 步 Sinkhorn-Knopp 替代中心化；加 KoLeo 正则（$-\frac{1}{n}\sum_i\log\min_{j\neq i}\|\mathbf x_i-\mathbf x_j\|$）把批内特征在超球面上推匀。先训 11 亿参数的 ViT-g/14，再蒸馏出 ViT-S/14（21M）、B/14（86M）、L/14（304M），全部 Apache 2.0 开源。冻结骨干只训线性头就能在分类、分割和深度上拿到强基线。
  • Registers（Darcet et al., ICLR 2024）：放大 ViT 后，DINOv2、CLIP 等模型都会在低纹理背景 patch 上出现范数高出正常值一个量级的「伪影 token」——网络把冗余背景块挪作全局草稿纸，丢弃局部信息去存全局摘要，污染注意力图。在输入序列里加几个可学习寄存器 token（registers）专门承接全局计算，背景伪影立刻消失，特征图变干净。
  • DINOv3（Siméoni et al., 2025）：把无监督训练推到 70 亿参数 ViT-7B（$p=16$，2D 轴向 RoPE）和 16.89 亿张图 LVD-1689M（另有 4.93 亿张遥感图 SAT-493M 版本）。长时间训练会出现全局分类继续涨、稠密分割/深度却倒退的退化现象；DINOv3 提出 Gram anchoring，用训练早期教师的 patch 间 Gram 矩阵（成对相似度 $X_G X_G^\top$）锚定后期学生的 Gram 矩阵 $X_S X_S^\top$，稳住局部结构。随后做高分辨率适配（训练最高 768 px，论文观察到 4K 以上输入的特征图仍稳定），蒸馏出 ViT-S/S+/B/L/H+ 与 ConvNeXt-T/S/B/L 全套小模型。采用自定义 DINOv3 License（允许商用，但禁止 ITAR 管制及军事、核、间谍、武器等用途）。截至 2026-11 尚无 DINOv4 发布。

为什么机器人常用 DINO

DINOv2 / DINOv3 的 patch 特征天然具备跨实例、跨视角的语义对应：杯子 A 的把手和另一只不同颜色、不同朝向的杯子 B 的把手在特征空间里余弦相似度最高，可直接用于一次示教的关键点迁移，也是 VGGT、LRM、TRELLIS 等 3D 模型（见 3D 基础模型 · 多视图、LRM、原生 3D）和 OpenVLA 的视觉骨干。与 SLAM 前端 的 ORB / SuperPoint 特征点相比：SLAM 特征追求同一场景上的亚像素重复率以便几何求解；DINO 以 14–16 像素的粗粒度换取跨物体、跨外观的部件级语义对应。

图文对齐：CLIP → SigLIP → SigLIP 2

CLIP（Radford et al., ICML 2021）用图像编码器和文本编码器把图文各自映射到同一单位球面，在 4 亿对互联网图文上用对称 InfoNCE 对比损失拉近配对图文、推远批内其余组合。SigLIP（Zhai et al., ICCV 2023）把批内全局 softmax 换成每个 $(i,j)$ 对独立的二分类 sigmoid 损失。

推导：InfoNCE 与逐对 Sigmoid 的梯度差别

  1. 批内 $B$ 对图文经编码与 $\ell_2$ 归一化得 $\mathbf u_i,\mathbf v_j\in\mathbb R^d$，余弦相似度矩阵 $s_{ij}=\mathbf u_i^\top\mathbf v_j$。

  2. CLIP 在相似度矩阵的行（图→文）与列（文→图）两个方向各做一次 softmax，温度 $\tau_{\text{cl}}$ 可学习：

    $$\alpha_{ij}=\frac{\exp(s_{ij}/\tau_{\text{cl}})}{\sum_{k=1}^B \exp(s_{ik}/\tau_{\text{cl}})},\qquad \beta_{ij}=\frac{\exp(s_{ij}/\tau_{\text{cl}})}{\sum_{k=1}^B \exp(s_{kj}/\tau_{\text{cl}})},\qquad \mathcal L_{\text{CLIP}}=-\frac{1}{2B}\sum_{i=1}^B(\log\alpha_{ii}+\log\beta_{ii})$$

  3. 对缩放 logit $z_{ij}=s_{ij}/\tau_{\text{cl}}$ 求偏导，得到每个格子的梯度：

    $$\frac{\partial\mathcal L_{\text{CLIP}}}{\partial z_{ij}}=\frac{1}{2B}\big(\alpha_{ij}+\beta_{ij}-2\delta_{ij}\big)$$

    关键性质：因为 $\sum_k \alpha_{ik}=1$，同一行里所有格子互相抢概率质量。分布式训练时必须做跨卡 all-gather 凑齐整行整列才能算分母；若批内两张图恰好配了语义相同的文本，非对角格 $(1,2)$ 会被硬当负样本压低，且 $\alpha_{11}$ 和 $\alpha_{12}$ 不可同时接近 1。

  4. SigLIP 取消 softmax 归一化，对每一对 $(i,j)$ 独立算二元交叉熵（正对 $y_{ij}=+1$，负对 $y_{ij}=-1$），用可学习缩放 $t_{\text{sig}}=e^{t'}$ 和偏置 $b_{\text{sig}}$ 构造 logit $\tilde z_{ij}=t_{\text{sig}}\,s_{ij}+b_{\text{sig}}$：

    $$\mathcal L_{\text{SigLIP}}=-\frac{1}{B}\sum_{i=1}^B\sum_{j=1}^B \log\sigma\!\big(y_{ij}\,\tilde z_{ij}\big)$$

    批内负样本对的数量是正样本对的 $B-1$ 倍，训练初期负样本梯度会压垮模型；原文初始化 $t'=\log 10$（即 $t_{\text{sig}}=10$）和 $b_{\text{sig}}=-10$，让初始预测默认偏向负类，开局平稳。

  5. 对 $\tilde z_{ij}$ 求偏导，第 $(i,j)$ 格的梯度只依赖这一对自身，与同行的其他样本完全解耦：

    $$\frac{\partial\mathcal L_{\text{SigLIP}}}{\partial \tilde z_{ij}}=-\frac{y_{ij}}{B}\big(1-\sigma(y_{ij}\tilde z_{ij})\big)=\begin{cases}-\tfrac{1}{B}\big(1-\sigma(\tilde z_{ij})\big), & y_{ij}=+1\\ +\tfrac{1}{B}\,\sigma(\tilde z_{ij}), & y_{ij}=-1\end{cases}$$

    解耦带来两个收益：跨卡训练可分块轮转计算而不必攒出完整的 $B\times B$ 显存矩阵（论文测到 $B=10^6$，32k 时即接近饱和）；多正样本（两图同文）之间没有求和为 1 的互斥上限。

零样本分类、语义与空间取舍、SigLIP 2

  • 零样本分类：把类别名填入模板（如 "a photo of a {class}"）经文本编码器算出原型向量 $\mathbf v_1,\dots,\mathbf v_C$，直接拿它们当线性分类头权重，取 $\arg\max_c\,\mathbf u^\top\mathbf v_c$。
  • 全局强、稠密弱：图文对比只监督整张图的全局向量，文本描述很少写清每个像素的精确边界，因此 CLIP / SigLIP 擅长开放语义识别，但在跨图几何对应和细粒度定位上明显弱于 DINO——这正是两者互补的原因。
  • SigLIP 2（Tschannen et al., 2025）：在 sigmoid 对比损失之外同时加入三类信号：① 接轻量文本解码器做 captioning 与指代定位（LocCa 配方），补齐细粒度定位和 OCR；② 图像端加 EMA 自蒸馏与掩码 patch 预测，强化稠密特征；③ 多语言数据训练，并推出 NaFlex 变体保留原始长宽比与可变分辨率。Google 的 PaliGemma 与 $\pi_0$ 使用的正是 SigLIP-So400m/14。

开放词表检测：DETR → DINO-DETR → Grounding DINO

DETR（Carion et al., ECCV 2020）把目标检测写成集合预测：解码器用 $N_q$ 个可学习 object query 交叉注意图像特征，直接输出 $N_q$ 个（类别, 框），训练用匈牙利算法做真值与预测的最优一一匹配，推理无需锚框与 NMS。

设图中有 $M$ 个真值物体，补 $N_q-M$ 个「无物体 $\varnothing$」凑成 $N_q$ 个。匈牙利匹配寻找排列 $\hat\pi\in\mathfrak S_{N_q}$ 最小化总匹配代价：

$$\begin{aligned}\hat\pi&=\arg\min_{\pi\in\mathfrak S_{N_q}}\sum_{k=1}^{M} C_{\text{match}}\big(k,\,\pi(k)\big)\\ C_{\text{match}}(k,l)&=-\hat p_l(c_k)+\lambda_{\text{L1}}\|\mathbf b_k-\hat{\mathbf b}_l\|_1+\lambda_{\text{GIoU}}\big(1-\mathrm{GIoU}(\mathbf b_k,\hat{\mathbf b}_l)\big)\end{aligned}$$

每个真值恰好只分到一个预测框，其余 $N_q-M$ 个预测被监督推向 $\varnothing$，所以训练完模型自己抑制重复框，省掉 NMS。

DINO-DETR：把 DETR 训快、训准

原版 DETR 早期匈牙利匹配抖动大，要训 500 个 epoch。DINO-DETR（Zhang et al., ICLR 2023）——再次强调，它与自监督的 DINO ViT 无关——靠三处改动将训练压到 12–36 epoch 并刷新 COCO 精度：

  • 对比去噪训练（CDN）：训练时额外喂给解码器一批「真值框加小噪声（正 query）」和「加大噪声（负 query）」，绕开不稳定的匈牙利匹配直接教解码器既会微调真框又会拒绝近处重复框。
  • 混合 query 选择：编码器输出得分最高的 $N_q$ 个位置特征用来初始化解码器的4D 锚框坐标，而 query 的内容向量保持可学习，避免编码器误选导致的语义混淆。
  • Look Forward Twice：解码器第 $l+1$ 层微调框的梯度同时回传更新第 $l$ 层的框预测参数，让后层监督前层。

Grounding DINO：把检测变成「框与文本 token 匹配」

Grounding DINO（Liu et al., ECCV 2024）把 DINO-DETR 的固定类别分类头换成框特征与输入文本 token 的点积相似度，在 O365 + GoldG + Cap4M 等检测与短语定位数据（沿用 GLIP 配方）上联合训练，实现任意文本开放词表检测。

它的四个模块全程做模态融合：图像骨干（Swin-T / Swin-L）+ 文本骨干（BERT-base） → 特征增强器（多层图像↔文本双向交叉注意力）→ 语言引导的 query 选择（按与文本的相似度从图像特征里挑前 $N_q$ 个 token 初始化位置 query）→ 跨模态解码器（每层依次做 query 自注意力、图像交叉注意力、文本交叉注意力）。

推理时把要找的类别用 " . " 拼成一条提示词（如 "red mug . wrench ."），模型对每个预测框输出它与提示词里每个子词 token 的 sigmoid 得分，再用两个阈值过滤：

  • box_threshold（$\theta_{\text{box}}$）：只保留「对所有文本 token 的最高得分 $\ge\theta_{\text{box}}$」的候选框；调低会放出背景假框，调高容易漏检。
  • text_threshold（$\theta_{\text{text}}$）：对保留下来的框，把得分 $\ge\theta_{\text{text}}$ 的文本 token 拼成它的输出短语标签；调过高会把修饰词（如 red）切掉甚至变成空标签。

后续系列与同类模型

  • 开源现状（截至 2026-11）：原版 Grounding DINO（Swin-T / Swin-B）完全开源（Apache 2.0）。后续的 Grounding DINO 1.5（20M 定位图，含 Pro 与 Edge 版）、Grounding DINO 1.6 与 DINO-X（统一输出框、掩码、关键点与区域描述）均由 IDEA Research 主导，但完整权重未作传统开放下载，主要通过 DeepDataSpace 等托管 API / 商业平台调用。
  • GLIP（CVPR 2022）：最早把目标检测与短语定位统一为区域–词对齐任务（DyHead + BERT），Grounding DINO 沿用了它的定位预训练范式与数据。
  • OWL-ViT（ECCV 2022）与 OWLv2（NeurIPS 2023）：不做复杂跨模态解码器，直接在 CLIP 风格 ViT 的每个 patch token 上挂轻量框回归头和分类头；OWLv2 用 100 亿网络图自训练扩展，开源 Apache 2.0，常用于机器人自动标注。
  • YOLO-World（CVPR 2024）：在 YOLOv8 上加可重参数化的图文特征金字塔（RepVL-PAN），推理前可把固定词表的文本嵌入离线并入卷积权重，速度达到边缘实时级别。

可提示分割：SAM → SAM 2 → SAM 3

SAM（Kirillov et al., ICCV 2023）把分割做成交互式提示任务：输入一张图和任意几何提示（正/负点击、边界框、粗掩码），输出对应的像素级掩码。SAM 不认识物体类别，只输出无语义标签的几何区域。

解耦架构决定它的交互体验：重的图像编码器（MAE 预训练 ViT-B/L/H，MAE 见 He et al., CVPR 2022）对 1024×1024 图像只跑一次（ViT-H 在 A100 上约 0.15 s）算出 $64\times 64$ 特征图；轻的提示编码器和 2 层掩码解码器每次响应点击仅需毫秒级（导出后在浏览器 CPU 上也能约 50 ms 完成）。

多掩码解歧义：在杯把上点一下，用户可能想要「杯把」「整个杯子」或「杯子+托盘」。SAM 因此固定同时输出 3 个嵌套候选掩码 $M_1,M_2,M_3$（子部件 / 部件 / 整体）及各自预测质量分 $\widehat{\mathrm{IoU}}_1,\widehat{\mathrm{IoU}}_2,\widehat{\mathrm{IoU}}_3$；训练时只对 3 个里与真值误差最小的那一支反传梯度，让三条分支自然分化出不同粒度。框提示歧义小，一般直接取单掩码输出。

SA-1B 三阶段数据引擎：① 人工辅助（标注员点选，模型实时辅助，12 万图得 430 万掩码）→ ② 半自动（模型先自动标出显著物体，人工补标难例，18 万图增 590 万掩码）→ ③ 全自动（每图撒 $32\times 32$ 规则点网格批量生成并按稳定性过滤，最终产出 1,100 万图、11 亿掩码）。代码与权重 Apache 2.0。

SAM 2、SAM 3 / 3.1 与轻量变体

  • SAM 2（Ravi et al., ICLR 2025）：把可提示分割扩展到视频。换用层级视觉骨干 Hiera（多尺度特征、速度大增）；新增记忆库（memory bank）存历史关键帧与提示帧的空间特征、记忆注意力在每帧把当前特征与记忆融合，以及 occlusion 头判断目标当前帧是否被完全遮挡。流式逐帧运行，单卡 A100 上 Hiera-B+ 约 43.8 FPS、Hiera-L 约 30.2 FPS（启用编译优化）。配套 SA-V 数据集含 5.09 万段视频、64.26 万条 masklet（3,550 万张掩码）。Apache 2.0 开源。
  • SAM 3 与 SAM 3.1（Carion et al., 2025-11；3.1 于 2026-03）：把几何提示升级为可提示概念分割（PCS）——输入短名词短语（如 "red mug"）或示例框，单模型在图和视频里找出并跟踪所有匹配实例。整个模型约 8.48 亿参数，检测器和跟踪器共享一个 Perception Encoder 图像骨干（输入 1008×1008，$p=14$，只有部分层用全局注意力）；核心改动是加了全局 presence head，把「该概念图里有没有」和「实例在哪个位置」解耦，大幅减少图里没有目标时的幻觉输出；配套 SA-Co 数据引擎与基准覆盖约 400 万独特概念与难负例。H200 上单图约 30 ms。2026-03 发布的 SAM 3.1 保持接口兼容，引入 Object Multiplex：把目标分进容量为 16 的桶，每桶只做一次记忆编码和检索，单张 H100 上跟踪 128 个目标时比 2025-11 版快约 7 倍。两者采用 Meta 自定义 SAM License。截至 2026-11 为最新官方版本。3D 物体重建分支 SAM 3D Objects 见 3D 基础模型。
  • 轻量 SAM 一句话：边缘部署常用 MobileSAM（把 ViT-H 编码器蒸馏成 TinyViT）、EfficientSAM（CVPR 2024，用 SAMI 掩码预训练训轻量编码器）和 EfficientViT-SAM（CVPRW 2024，换 EfficientViT 骨干基本不掉点）。

文本 → 掩码 → 跟踪：Grounded SAM 与单模型对比

SAM 1 / 2 没有语言接口，Grounding DINO 只出矩形框不出像素轮廓。Grounded SAM（Ren et al., 2024）把两者拼成两阶段流程，Grounded-SAM-2 再把第二阶段换成 SAM 2 接上视频跟踪：

  1. 文本 → 边界框：输入图像（或视频首帧）和提示词，Grounding DINO 跑完按 $\theta_{\text{box}},\ \theta_{\text{text}}$ 筛出框与短语标签。
  2. 边界框 → 实例掩码：把每个框直接当 box prompt 喂给 SAM / SAM 2，换取贴合边缘的像素掩码。
  3. 首帧掩码 → 视频跟踪：在 Grounded-SAM-2 里，首帧掩码写入 SAM 2 记忆库，后续帧逐帧流式传播；若新物体中途入镜，需每隔若干帧重跑一次检测器补注册。

错误单向传递：阈值全压在第一步的 Grounding DINO 上。SAM 不做类别校验——第一步漏框，掩码永久缺失；第一步把反光或桌面阴影框进来，SAM 照样抠出一个干净轮廓，SAM 2 还会把这个假掩码一路跟到视频结尾。

单目深度：Depth Anything 的数据引擎

相对深度与度量深度的区别、焦距–距离歧义、尺度-平移不变损失推导及单目模型总表已在 3D 基础模型 · 单目几何 讲过，这里不重复，只拆解 Depth Anything 系列最关键的设计：为什么「教师–伪标签–学生」这套数据引擎让同一个网络结构精度大涨。

模型结构极简：编码器直接用预训练 DINOv2 ViT，解码器接 DPT（Ranftl et al., ICCV 2021）——抽取编码器 4 个中间层特征，经卷积重排成多尺度金字塔并逐级上采样融合，输出逐像素相对视差 $\hat D$。与 仿真 RL 里的教师–学生蒸馏 不同，RL 蒸馏是把仿真特权状态压进无特权学生，而 Depth Anything 的教师和学生都只看 RGB，教师靠更大容量或更干净的数据源把海量无标注真实图变成伪监督。

V1 → V2：为什么扔掉真实深度标签训教师

  • Depth Anything V1（Yang et al., CVPR 2024）：先在 150 万张有深度标注的图上训教师，再用教师给 6,200 万张无标注真实图打伪视差标签 $\tilde D$。训学生时两招缺一不可：① 对无标注图施加强扰动（强颜色抖动、高斯模糊、CutMix 拼图），逼学生从困难视角对齐干净图上的伪标签，避免学生退化成教师的简单复读机；② 语义特征对齐损失：把学生编码器特征 $f_{\text{enc}}$ 与冻结的原始 DINOv2 特征 $f_{\text{frozen}}$ 做余弦对齐，但只在余弦相似度低于 0.85 的像素上惩罚（$\alpha=0.85$ 容忍度），既保住 DINOv2 的高层语义，又留出空间让特征去适应几何深度。
  • Depth Anything V2（Yang et al., NeurIPS 2024）：发现 V1 的瓶颈不在架构，而在真实深度标注本身很脏——LiDAR 稀疏、双目匹配在弱纹理和遮挡边缘出飞点、RGB-D 红外结构光遇到玻璃、反光金属和细杆直接变空洞（NaN）。用脏数据训出来的教师，会把边缘发糊和玻璃空洞写进 6,200 万张伪标签。V2 干脆只用 59.5 万张纯合成图（精确无噪、细杆与透明物体完整）训出最大的 DINOv2-Giant（1.3B）教师，再用它给 6,200 万张真实无标注图打伪标签，最后蒸馏成 4 个尺度的学生：Small（24.8M）、Base（97.5M）、Large（335.3M）、Giant（1.3B）。合成数据保证细节锐利，海量真实伪标签弥合合成到真实的视觉域差；另有在室内（Hypersim）/ 室外（Virtual KITTI）微调的度量深度版本。
  • Video Depth Anything（CVPR 2025 Highlight）：在 V2 编码器上把 DPT 换成轻量时空头，配合重叠关键帧对齐策略，消除逐帧单目深度在超长视频里的闪烁漂移。
  • Depth Anything 3（ICLR 2026）：普通 DINOv2 骨干同时预测深度图与每像素射线，单图退化为强单目深度、多图直接做多视图重建（详见 3D 基础模型 · 多视图）。截至 2026-11 为该系列最新版本。

视觉编码器怎么选、怎么合

三类视觉骨干各有所长，也各有硬伤：CLIP / SigLIP 懂语言语义但定位粗；DINOv2 / DINOv3 几何与局部对应强但不认词；SAM 边界锐利但缺类别语义。近年有三条融合路线把这些能力凑到一起：

  1. 推理时双编码器拼接：Prismatic VLMs（ICML 2024）系统对比发现把 DINOv2 ViT-L/14 和 SigLIP ViT-So400m/14 在同分辨率（224×224，各出 $16\times 16=256$ 个 patch token）上按通道拼在一起再投影给 LLM，空间与语义双赢。OpenVLA（CoRL 2024）直接沿用这套双骨干，代价是视觉前端算力翻倍。
  2. 多教师蒸馏成单编码器：AM-RADIO（CVPR 2024）把 CLIP、DINOv2、SAM 蒸馏进同一个学生 ViT（用轻量适配头分别对齐各教师），推理只需跑一次；RADIOv2.5（CVPR 2025）用多分辨率训练和教师损失重平衡解决分辨率切换时的特征跳变与教师失衡。面向机器人的 Theia（CoRL 2024）把 CLIP、ViT、DINOv2、SAM、Depth Anything 五个视觉基础模型的空间 token 蒸馏进轻量单编码器（只用 ImageNet 的 120 万张图，H100 上约 150 GPU 小时），在仿真（CortexBench）和真机操作任务上超过单一教师。
  3. 挖掘对比模型的中间层：Perception Encoder（Meta, NeurIPS 2025 Oral）发现纯图文对比训练其实已经学到了强稠密与空间特征，只是最后几层为了匹配全局文本把空间细节压扁了；取出中间层特征再做轻量空间/语言对齐，单个编码器即可同时胜任分类、定位与密集任务（SAM 3 的图像骨干就是它）。

部署时最常踩的五个坑

① 分辨率与小物体：VLA 默认的 224×224 / $p=14$ 只有 $16\times 16$ 格，桌面上的螺丝、线缆、杯把可能还不到一格。拉高分辨率或切局部裁剪能立竿见影，但全局注意力成本随分辨率四次方涨。

② 机械臂自身入镜：机械臂连杆与反光夹爪常被 SAM 和桌面物体粘成同一块掩码，或被 "metal tool" 误检。工程上常用机器人 URDF + 当前关节角正运动学渲染出机械臂自身掩码，在分割结果里显式减去。

③ 阈值换环境就飘：官方示例默认 $\theta_{\text{box}}=0.35$、$\theta_{\text{text}}=0.25$，换了光照、相机或桌面后可能大面积漏检或狂出假框；务必在目标相机和真实背景上留一小批验证图标定阈值。

④ 推理时延与控制频率失配：已核对的典型单次耗时——SAM 1 ViT-H 编码 ~150 ms（A100），掩码解码 ~50 ms（浏览器 CPU）；SAM 2 Hiera-B+ ~43.8 FPS、Hiera-L ~30.2 FPS（A100，编译优化）；SAM 3 单图 ~30 ms（H200），SAM 3.1 跟踪 128 个目标时比 SAM 3 快约 7 倍（H100）；Depth Anything V2 Small（24.8M，518×518）在 A100 上不到 10 ms。把检测、分割、深度、位姿串起来很容易超过 50–100 ms，不能塞进 50 Hz 同步控制环，应放异步感知线程或只在任务关键帧触发。

⑤ 许可证红线（商用必核对）：同名系列不同版本、甚至同一版本不同尺寸的许可证都可能不同，上生产前必须核对具体权重卡片（见下表）。

自测

1. DINO（Caron 2021）和 Grounding DINO 是什么关系？Grounding DINO 的视觉骨干是 DINO ViT 吗？

两者没有继承关系，只是名字撞车。自监督的 DINO 是「self-distillation with no labels」，训图像表征；Grounding DINO 里的 DINO 指检测器 DINO-DETR（DETR with Improved deNoising anchOr boxes）。Grounding DINO 原文用 Swin Transformer 做图像骨干、BERT 做文本编码器，并未使用 DINO ViT。

2. Grounded SAM 和 SAM 3 差在哪？在视频里如果 Grounding DINO 首帧框错了，SAM 2 会自动纠正吗？

Grounded SAM 是 Grounding DINO（文本→框）+ SAM（框→掩码）两模型串联的推理流程；SAM 3 用单个统一模型（Perception Encoder + presence head + 跟踪记忆）直接完成「短语/示例框 → 图和视频里所有实例的掩码」。SAM / SAM 2 不懂语义类别，首帧框错了就会抠出错误区域的掩码，并靠视觉记忆把错掩码一路跟下去，不会纠正类别。

3. 做 VLA 视觉骨干，选 DINOv2 还是 SigLIP？为什么 OpenVLA 要把两者拼起来，而 $\pi_0$ 只用 SigLIP？

SigLIP 经图文对齐，开放语义和指令理解强，但空间局部定位不如 DINOv2；DINOv2 的稠密 patch 特征擅长空间几何与部件对应，却没有语言对齐。OpenVLA 为在 224×224 下兼得两者，并行跑 DINOv2 + SigLIP 按通道拼接；$\pi_0$ 直接继承 PaliGemma（SigLIP-So400m + Gemma）整套 VLM 权重，只有一个视觉编码器，省去双骨干开销，空间能力靠机器人数据上的联合训练补。

4. DINO 训练中，只留锐化去掉中心化会塌缩到哪种解？反过来只留中心化去掉锐化呢？

只留锐化（低温 $\tau_t$、无中心化）会让微小偏置被指数放大，所有样本都输出同一个 one-hot 维度，发生单模塌缩（批平均熵 $H(\bar P_t)\to 0$）。只留中心化去掉锐化（高温 $\tau_t$）会把每张图的输出压平到均匀分布 $1/K$，发生均匀塌缩（单样本熵 $\overline{H(P_t)}\to\log K$）。两者合力才能保持低单样熵与高批平均熵。

5. CLIP 的 InfoNCE 和 SigLIP 的逐对 sigmoid 损失，在「批内出现两条同义图文对」和「超大 batch 训练」上差在哪？

InfoNCE 在行和列上做全局 softmax，概率和固定为 1：批内出现同义图文对时，非对角格被硬当负样本且与正对抢概率，同时分布式训练必须跨卡通信算完整分母。SigLIP 每个 $(i,j)$ 对独立做二分类，梯度与其他样本完全解耦，不仅允许分块跨卡扩展到极大 batch，而且多正样本之间不存在和为 1 的互斥冲突。

6. Depth Anything V2 为什么只用 59.5 万张合成图训教师，反而比 V1 用 150 万真实深度图训教师更准？

真实深度传感器在透明玻璃、反光表面、细杆和物体边缘有大量空洞与飞点，用脏标签训出的教师会把这些系统缺陷复制进 6,200 万张伪标签里。合成图的深度逐像素精确无空洞，用 1.3B 的 DINOv2-G 教师从合成图学到锐利几何，再给 6,200 万张真实无标注图打伪标签，既避开了真实传感器噪声，又借海量真实图消除了合成到真实的视觉域差。

7. 要把「开放词表抠点云 + 单目深度」上线到商用机械臂产品，选权重时有哪些容易漏掉的坑？

一是许可证：Depth Anything V2 只有 Small（24.8M）是 Apache 2.0，Base/Large/Giant 是 CC-BY-NC-4.0 禁商用；SAM 3 和 DINOv3 是自定义许可证，需审合规条款；Grounding DINO 1.5+/DINO-X 没给开放本地权重。二是几何与系统坑：低分辨率漏小零件、反光机械臂连杆被并入掩码（需 URDF 渲染减除）、掩码边缘 2 像素背景导致点云飞点（需腐蚀掩码 + 滤波），以及串联时延超控制周期需异步运行。
