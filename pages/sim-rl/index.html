仿真 RL 与行为克隆

同事说的「仿真 RL」通常是两类事：在 GPU 并行仿真里从零训底层控制器（足式行走、人形全身控制、灵巧手），或者先用示教 SFT 一个 VLA，再在仿真基准里用任务成功作奖励做 RL 微调。这一页讲清楚仿真 RL 怎么做、为什么要在仿真里做，以及它和采数据做行为克隆（BC）差在哪里、各自在哪赢、怎么结合。

两种范式：行为克隆 vs 仿真 RL

行为克隆（BC，Behavior Cloning）把专家示教数据集 $\mathcal D=\{(o_i,a_i)\}$ 当作监督学习样本，最大化策略在示教动作上的对数似然（或最小化回归 / flow matching 损失）：$\max_\theta\ \mathbb E_{(o,a)\sim\mathcal D}[\log\pi_\theta(a\mid o)]$。

仿真强化学习（Sim RL）让策略自己在仿真环境里试错采样轨迹 $\tau=(s_0,a_0,r_0,\dots,s_T)$，根据每步奖励 $r_t$ 最大化期望折扣回报：$\max_\theta\ J(\theta)=\mathbb E_{\tau\sim\pi_\theta}\!\big[\sum_{t=0}^{T-1}\gamma^t r_t\big]$。

工程里说的「仿真 RL」实际分成两条技术路线，两者的前提、算力分布和难点都不同：

  • 路线 A · 从零训底层控制器：面向足式行走、人形全身控制与动作跟踪、灵巧手在手操作。用 GPU 并行仿真跑几千个环境 + PPO + 域随机化 + 教师–学生蒸馏，再零样本或微调 sim-to-real，几乎不用人类遥操作示教。
  • 路线 B · 仿真里用 RL 微调 VLA：面向桌面视觉–语言操作。先用示教数据 SFT 出一个能动的 VLA，再在 LIBERO、ManiSkill、RoboTwin 等仿真基准里以任务成功作奖励做在线 RL（SimpleVLA-RL、RL4VLA、VLA-RL、$\pi_{\text{RL}}$）。

行为克隆为什么不够

监督学习假设训练和测试同分布（i.i.d.）。机器人控制是序贯决策：当前步动作决定下一步看到什么状态，微小预测误差会改变后续状态分布。

  • 协变量偏移与复合误差：训练只在专家状态分布 $d_{\pi^*}$ 上监督；部署时策略 $\pi$ 偶发小错，把自己带到没见过的状态，误差越来越大，总代价按步数的平方增长。
  • 示教里没有「出错怎么拉回来」：熟练操作员采出的轨迹几乎都是成功的，物体滑落、夹偏、机身失衡这类边缘状态在 $\mathcal D$ 里几乎为空，策略遇到扰动不知道如何恢复。
  • 性能被示教上限锁死：遥操作受延迟与人类反应速度限制，BC 策略通常比真机物理极限慢得多，也很难超过示教者的成功率。
  • 许多任务无法遥操作：四足越野的 12 关节高频协调、人形抗推平衡、多指灵巧手在手翻转物体涉及毫秒级接触切换，人类根本没法用手柄或手套给出示范。

复合误差的直观推导（Ross, Gordon, Bagnell, AISTATS 2011）

设单步代价 $c(s,a)\in[0,1]$，专家完美执行 $C(\pi^*)=0$。假设学到的策略 $\pi$ 在专家访问的状态分布 $d_{\pi^*}$ 上单步犯错概率不超过 $\varepsilon$（即 $\mathbb E_{s\sim d_{\pi^*}}[\mathbb P(\pi(s)\ne\pi^*(s))]\le\varepsilon$）。记 $C(\pi)=\mathbb E_{\tau\sim\pi}[\sum_{t=0}^{T-1}c(s_t,a_t)]$：

  1. 在前 $t$ 步都没犯错的条件下，第 $t$ 步的状态仍在专家分布 $d_{\pi^*}$ 上，因此「首次犯错恰好发生在第 $t$ 步」的概率至多为 $\varepsilon$（记 $p_t\le\varepsilon$）。

  2. 一旦在第 $t$ 步偏离专家轨迹，剩余的 $T-t$ 步都落在训练未覆盖的分布外状态；最坏情况下每步代价都是上界 $1$，贡献总代价至多 $T-t$：

    $$C(\pi\mid\text{首次犯错在 }t)\le T-t$$

  3. 对首次犯错的时刻 $t=0,\dots,T-1$ 求和，得到关于步数 $T$ 的二次上界（Ross et al., 2011 定理 2.1）：

    $$C(\pi)\le\sum_{t=0}^{T-1}\varepsilon\,(T-t)=\frac{T(T+1)}{2}\,\varepsilon\le T^2\varepsilon$$

    更一般地，若专家总代价非零且单次出错的恢复代价上界为 $u$，则 $C(\pi)\le C(\pi^*)+O(uT^2\varepsilon)$。长程任务里 $T$ 翻倍，最坏误差翻 4 倍。

  4. DAgger（Dataset Aggregation）把上界降回线性：每轮让当前策略 $\pi_i$ 自己跑轨迹，在它实际访问到的状态 $s\sim d_{\pi_i}$ 上向专家查询正确动作并并入 $\mathcal D$。用无悔在线学习迭代 $N$ 轮、得到在自身分布 $d_{\hat\pi}$ 上的平均单步误差 $\varepsilon_N$ 后，每次犯错不再永久漂走，只付单步恢复代价 $u$（定理 4.1）：

    $$C(\hat\pi)\le C(\pi^*)+u\,T\,\varepsilon_N+O(1)$$

RL 在连续控制里长什么样

MDP、策略梯度、PPO 的 clip 代理目标与 GAE 已在 LLM RL 基础 · PPO 与 GAE 推导过。机器人连续控制和 LLM 的主要区别有三处：动作是连续向量、策略输出要经过底层控制器、单步奖励通常是稠密的且 $\gamma<1$。

  • 对角高斯策略：动作 $a_t\in\mathbb R^{d_a}$ 从各维独立高斯采样，$a_t\sim\mathcal N(\mu_\theta(o_t),\operatorname{diag}(\sigma^2))$。网络输出均值 $\mu_\theta(o_t)$，标准差 $\sigma$ 常取与状态无关的可学习向量（训练时提供探索噪声，部署时取均值 $\mu_\theta(o_t)$）。对数概率闭式可算，可直接代入 PPO 的重要性比值 $\rho_t=\exp(\log\pi_\theta-\log\pi_{\theta_{\text{old}}})$：
$$\log\pi_\theta(a\mid o)=-\frac{1}{2}\sum_{j=1}^{d_a}\left(\frac{(a_j-\mu_{\theta,j}(o))^2}{\sigma_j^2}+2\log\sigma_j+\log 2\pi\right)$$
  • PD 目标与 action_scale：底层控制很少直接输出裸力矩 $u_t$，而是输出相对默认站立姿态 $q_{\text{def}}$ 的偏移，经缩放系数 $\alpha_a$（legged_gym 默认 0.5）转成目标关节角，再交给底层 PD 控制器算力矩（详见 运动空间 · 动作怎么执行）：
$$q^*_t=q_{\text{def}}+\alpha_a\,a_t,\qquad u_t=K_p\,(q^*_t-q_t)-K_d\,\dot q_t$$
  • 控制频率与 decimation：刚体接触需要高频积分防止穿模（典型 $\Delta t_{\text{sim}}=0.005\text{ s}$，200 Hz），但策略网络不必每步都跑。设 decimation $D_{\text{dec}}=4$，策略每 4 个物理步推理一次（$\Delta t_{\text{ctrl}}=0.02\text{ s}$，50 Hz），期间目标 $q^*_t$ 保持，PD 在每个 200 Hz 物理子步里按最新 $q_t,\dot q_t$ 重算力矩 $u_t$。
  • 价值网络与 GAE：连续控制常取 $\gamma=0.99,\ \lambda=0.95$。每轮由 $N_{\text{env}}$ 个并行环境各走 $K_{\text{step}}$ 步（例如 legged_gym 的 $4096\times 24=98{,}304$ 步），用 $V_\phi(s_t)$ 和 GAE 算出 $\hat A_t$ 与目标回报 $\hat R_t=\hat A_t+V_\phi(s_t)$，再拆成多个 mini-batch 做若干 epoch 的 PPO 更新。
# 连续控制 PPO 单轮训练循环（PyTorch / Isaac 风格伪代码）
for iteration in range(num_iterations):
    # 1) 在 GPU 上同步推进 N_env 个环境，收集 K_step 步 rollout
    for t in range(K_step):
        mu, std = actor(obs)                         # obs: [N_env, d_o]
        dist = Normal(mu, std)
        act = dist.sample()                          # act: [N_env, d_a]
        logp_old[t] = dist.log_prob(act).sum(-1)
        val_old[t]  = critic(priv_state)             # 非对称 critic 可读特权状态
        # 环境内部做 D_dec 次物理子步：q* = q_def + alpha_a * act -> PD -> 积分
        obs, priv_state, rew[t], done[t], timeout[t] = vec_env.step(act)

    # 2) 用 GAE 算优势（注意：超时截断需 bootstrap，真摔倒终止不 bootstrap）
    adv, ret = compute_gae(rew, val_old, done, timeout, critic(priv_state), gamma=0.99, lam=0.95)
    adv = (adv - adv.mean()) / (adv.std() + 1e-8)

    # 3) 对这批 N_env * K_step 条转移做若干 epoch 小批量 PPO 更新
    for epoch in range(num_epochs):
        for mb in minibatches(obs, priv_state, act, logp_old, adv, ret):
            ratio = (Normal(*actor(mb.obs)).log_prob(mb.act).sum(-1) - mb.logp_old).exp()
            loss_pi = -torch.min(ratio * mb.adv, ratio.clamp(1 - eps, 1 + eps) * mb.adv).mean()
            loss_v  = ((critic(mb.priv_state) - mb.ret) ** 2).mean()
            loss    = loss_pi + c_v * loss_v - c_ent * entropy.mean()
            optimizer.zero_grad(); loss.backward(); optimizer.step()
易错：终止 vs 超时截断

一集走到最大步数 $T$ 被强行截断（timeout）并不是机器人摔倒了。如果在超时步把下一状态价值 $V(s_T)$ 置零，critic 会以为「活到第 $T$ 步之后价值暴跌」，进而学出怪异的末端行为。正确做法是只在真失败终止时置零，超时步照常加 $\gamma V(s_T)$。

为什么要在仿真里：样本量与并行吞吐

无模型 on-policy RL（PPO）通常要吃掉 $10^7$ 到 $10^9$ 步环境交互才能从零收敛。真机跑不了这个量级，仿真提供四件真机给不了的东西：

  • 单卡数千环境并行：物理状态与神经网络权重都在同一张 GPU 显存里，省掉 CPU–GPU 拷贝，一步矩阵推进几千台机器人。
  • 免费且瞬间重置：一台机器人摔倒，写回初始关节角即可在微秒内重新开始，无需人工扶起或整理桌面。
  • 特权状态直接可读：地形高程图、脚底接触力、精确摩擦系数、物体 6D 位姿都是仿真内存里的张量。
  • 不怕摔坏硬件：随机策略早期会剧烈抽搐和翻滚，在真机上几秒就会断连杆或烧电机。

算一笔吞吐账：1 台 50 Hz 真机全速连续遥操作 1 小时（不计复位换场），最多采 $50\times 3600=1.8\times 10^5$ 步；而在 GPU 上同时跑 4,096 个环境，即便每个环境仅按 $1\times$ 实时步速推进，1 小时墙钟时间就能采 $4096\times 1.8\times 10^5\approx 7.37\times 10^8$ 步（相当于 4,096 小时、约 170 天真机经验）。Rudin et al.（CoRL 2021，legged_gym，arXiv:2109.11978）在单张 RTX 3090 上用 4,096 个并行环境，不到 4 分钟教会 ANYmal 平地行走，约 20 分钟学会翻越崎岖地形。

一个仿真 RL 任务要写什么

把一个真实控制需求翻译成可训练的仿真 RL 任务，需要写清五块配置，其中奖励函数的设计和调权往往占掉一半以上的研发时间：

  1. 观测（Observation）：策略输入只放真机拿得到的量（角速度、重力投影、关节角与速度、上一步动作、目标速度指令）；critic 或教师可额外读取地形高程、真实摩擦和接触力。
  2. 动作（Action）：PD 目标偏移 $q^*_t=q_{\text{def}}+\alpha_a a_t$，并限制范围防止目标突变。
  3. 奖励（Reward）：主任务项（如跟踪期望速度）叠加一排正则项（姿态稳定、能耗、加速度、动作变化率、防磕碰、步态抬脚）。
  4. 终止与重置（Termination / Reset）：机身或大腿触地即刻判负终止；重置时随机化初始关节角、朝向和速度指令，防止过拟合单一初始状态。
  5. 课程（Curriculum）：困难地形（楼梯、高坡、乱石）直接开训会全员摔倒拿不到正回报。legged_gym 按机器人能否走出当前地形格一半距离动态升降级，让每个策略始终待在「跳一跳够得着」的难度区。

易错：奖励投机（Reward Hacking）

优化器只会最大化你写下的公式，而不是你心里的意图。如果正则惩罚太大、跟踪权重太小，策略会学会「原地趴着不动」来拿零能耗；如果只给速度奖励而不加 action_rate 与 dof_acc，仿真里能跑很快，但动作每帧剧烈震荡，一上真机立刻过流报错。

动手：在浏览器里真的训练一个连续策略

下面跑的是完整的浏览器内连续控制 PPO（无外部库，纯 JS）：策略是一个 2 层 6→16→2 tanh 高斯 MLP（配独立 6→16→1 critic，共 277 个参数），任务是让二维点质量在执行噪声下绕过中间障碍到达右侧目标圆。每轮在 $N_{\text{env}}$ 个并行环境里采样完整轨迹，算 GAE 优势，做 4 个 epoch 的 PPO-clip + Adam 更新。

Sim-to-Real 的差距与办法

仿真里跑通不代表真机能跑通。Sim-to-real 差距主要来自三层：

  • 物理动力学差距：真实地面摩擦、连杆质量与质心偏差、柔性橡胶鞋底与物体弹性接触，刚体物理引擎只能近似建模。
  • 执行器与延迟差距：理想仿真给多少力矩立刻生效；真机有电机电流饱和、减速器摩擦与背隙、传感器滤波与通信延迟。Hwangbo et al.（Science Robotics 2019，arXiv:1901.08652）直接用真机电机采集指令–力矩序列，训一个神经网络 actuator network 放进仿真替代理想关节模型，大幅缩小足式迁移差距。
  • 感知 / 视觉差距：仿真渲染的光照、反光、纹理、运动模糊和镜头畸变与真实 RGB 相机仍有明显鸿沟——这正是纯视觉桌面操作很难靠纯仿真 RL 直接上真机的核心原因。

缩小差距的三类办法

  • 系统辨识（SysID）：实测质量、惯量、延迟与接触刚度，把仿真调准；或像 ASAP（He et al., 2025，arXiv:2502.01143）那样用真机 rollout 数据训一个残差动作模型塞回仿真对齐动力学。
  • 域随机化（DR，Domain Randomization）：把不确定的参数变成训练分布 $\xi\sim p(\xi)$——视觉 DR 随机化纹理光照（Tobin et al., IROS 2017，arXiv:1703.06907），动力学 DR 随机化质量、摩擦、阻尼与延迟（Peng et al., ICRA 2018，arXiv:1710.06537）。只要真机参数 $\xi_{\text{real}}$ 落在训练区间内，鲁棒策略就能扛过去。
  • 自动域随机化（ADR）：手调随机化区间很难两全——太窄包不住真机，太宽策略为了兜住极端情况会变得极度保守甚至学不动。OpenAI 魔方（Akkaya et al., 2019，arXiv:1910.07113）提出 ADR：从很窄的初始区间起步，只在策略在当前区间边界的成功率高于阈值时自动向外扩宽范围。

特权教师、学生蒸馏与非对称 Critic

纯靠域随机化逼出一个「对所有摩擦和地形一视同仁」的策略过于保守。更强的做法是利用仿真里的特权信息（地形高程、真实摩擦、外部推力、物体 6D 位姿），先训出好策略或好价值函数，再过渡到真机可部署的观测（本体历史、深度或 RGB 图像）。三条主流路线：

架构阶段数部署策略（Actor）输入训练期特权信息给谁代表工作

学生之所以能从纯本体历史里反推出「现在地面有多滑」或「手里物体有多重」，本质是隐式的在线系统辨识：同样的关节力矩 $u_t$ 下，如果脚底打滑（加速度和接触力异常），最近 $k$ 步的 $(o_{t-k+1:t}, a_{t-k:t-1})$ 序列里就藏着环境参数 $\xi_t$ 的指纹。

用 RL 微调 VLA：仿真基准与真机路线

桌面视觉操作从零做仿真 RL 几乎撞不到成功，但如果先用示教 SFT 出一个已经有 20%–80% 成功率的 VLA，再放进仿真里用任务成败作奖励做在线 RL（路线 B），就能同时解决探索冷启动和 BC 复合误差两件事。

仿真里的 VLA + RL 代表工作（截至 2026-11）

  • SimpleVLA-RL（Li, Zuo et al., 2025，arXiv:2509.09674）：基于 veRL，只用终局二值成功作奖励微调 OpenVLA-OFT。LIBERO 四套基准平均成功率从 SFT 的 91.0% 升到 99.1%（LIBERO-Long 86.5% → 98.5%）；极少数据设定下（每任务仅 1 条示教 SFT），LIBERO-Long 从 17.3% 拉升到 91.7%（四套平均 96.9%），并出现示教里没有的「推切（pushcut）」快捷动作。
  • RL4VLA（Liu et al., 2025，arXiv:2505.19789）：在 ManiSkill 上系统比较 PPO、GRPO、DPO 与 SFT 在视觉、语义、执行三个 OOD 维度上的泛化，结论是在线 PPO 对执行鲁棒性与语义泛化提升最大，同时保持视觉鲁棒性。
  • VLA-RL（Lu et al., 2025，arXiv:2505.18719）：将机械臂轨迹建模为多模态多轮对话，引入微调 VLM 作为过程奖励模型缓解稀疏奖励，在 LIBERO 的 40 个任务上让 OpenVLA-7B 比最强的微调基线高 4.5%。
  • $\pi_{\text{RL}}$ 与 RLinf（Chen et al., 2025，arXiv:2510.25889；分布式框架 RLinf，Yu et al., arXiv:2509.15965 / RLinf-VLA arXiv:2510.06710）：专门攻克 flow-based VLA（$\pi_0$、$\pi_{0.5}$）的在线 RL。LIBERO 上从少样本 SFT 起步，$\pi_0$ 57.6% → 97.6%、$\pi_{0.5}$ 77.1% → 98.3%；ManiSkill 上用 320 个并行环境、在 4352 个抓放任务上，$\pi_0$ 41.6% → 85.7%、$\pi_{0.5}$ 40.0% → 84.8%。
  • 推理 VLM 的纯成功信号仿真 RL：完全不做示教 SFT、直接让多模态推理模型以文本写动作并在仿真里只用 0/1 成功信号做多轮 RL（PEAR），详见 Robot-Use Agent · PEAR。

Flow / Diffusion VLA 的难点：算不出动作似然

自回归 VLA（如 OpenVLA、FAST token）把动作离散成 token，每步都有显式 softmax 概率，PPO / GRPO 可以直接拿 $\log\pi_\theta(a\mid o)$ 算重要性比值。但 $\pi_0$、$\pi_{0.5}$ 这类 flow matching 策略（原理见 π 系列 · Flow Matching）用确定性 ODE 把高斯噪声积分成连续动作块：不仅没有采样随机性，而且求动作边缘密度 $\log p_\theta(a\mid o)$ 要沿整条积分路径求雅可比散度，反传代价极高。目前有两条解法：

  1. 把去噪步改写成可算似然的随机链（$\pi_{\text{RL}}$）：Flow-Noise 在去噪网络外挂一个可学习噪声头，把每步去噪建为离散时间 MDP 从而算出精确对数似然；Flow-SDE 把确定性 ODE 改写成边缘分布等价的随机微分方程（SDE），每一步去噪转移都是闭式高斯分布，既引入探索噪声，又能直接逐去噪步计算 $\log\pi_\theta$ 代入 PPO / GRPO。
  2. 干脆不用策略梯度，改成优势条件化监督学习（$\pi^*_{0.6}$ 的 RECAP）：Physical Intelligence（arXiv:2511.14759，详链 π 系列 · $\pi^*_{0.6}$ 与 RECAP）单独训价值网络评估轨迹优势，把 Advantage: positive / negative 作为条件 token 拼进输入，用纯监督 flow matching 吃下全部好坏轨迹与人工纠正，推理时把条件钉在 positive 上采样，完全绕开动作似然。

跳过仿真器：真机 RL

对于插拔电路板、绕柔性线缆、叠衣这类仿真难以精确建模接触与外观的任务，另一条路是用高样本效率的 off-policy 算法直接在真机上做 RL：SERL（Luo et al., ICRA 2024，arXiv:2401.16013）与 HIL-SERL（Luo et al., Science Robotics / arXiv:2410.21845）结合少量示教、RLPD（离线数据 + 在线回放池混合更新）与人工在线接管纠正，在 1–2.5 小时真机训练内达到近 100% 精密装配成功率。批式真机迭代的 RECAP 则把自主 rollout 与人类介入统一成优势条件化重训，详见 π 系列 · $\pi^*_{0.6}$。

行为克隆与 RL 怎么结合

实际系统很少非此即彼，而是用 BC 解决探索和语义先验、用 RL 解决恢复和物理上限。常见组合有四种：

自测

任务一：要让双足人形机器人在碎石斜坡上行走并抵抗侧推，选采数据 BC 还是仿真 RL？为什么？

选仿真 RL（路线 A）。双足动态平衡需要 50–200 Hz 的全身力矩级协调，人类无法遥操作示教；该任务以本体感知为主，视觉 sim-to-real 差距小，速度与动作跟踪奖励清楚，在 GPU 并行仿真里配合域随机化与教师–学生蒸馏是最成熟路径。

任务二：要让双臂机械臂在开放厨房里按自然语言指令收拾各种碗筷和抹布，为什么目前以 BC / VLA 为主而不是纯仿真 RL 从零训？

四重障碍挡住从零仿真 RL：真实厨具与布料资产难以穷举建模，RGB 外观与光照的 sim-to-real 差距大，语义任务难以写出无漏洞的稠密奖励，且长程稀疏奖励下随机探索几乎碰不到成功。现实路线是用遥操作 / 手持夹爪示教配合 VLM 预训练做 BC，再用仿真或真机 RL 做后训练微调。

为什么行为克隆的误差上界是 $O(\varepsilon T^2)$，而 DAgger 能降到 $O(\varepsilon T)$？

BC 只在专家状态分布 $d_{\pi^*}$ 上保证单步出错率 $\le\varepsilon$；一旦在第 $t$ 步偏离，剩下 $T-t$ 步全在分布外，每步都可能出错，求和 $\sum_{t=0}^{T-1}\varepsilon(T-t)\approx\frac12\varepsilon T^2$。DAgger 把专家查询放到策略自己访问的状态分布 $d_{\hat\pi}$ 上，学会出错后立刻拉回，每次犯错只付常数恢复代价 $u$，总代价降为 $O(uT\varepsilon_N)$。

连续控制仿真 RL 里，decimation = 4 和 action_scale = 0.5 分别控制什么？

decimation = 4 表示策略每 4 个物理仿真步才推理一次新动作（如物理 200 Hz、策略 50 Hz），期间目标关节角保持不变、PD 环在每个物理步重算力矩。action_scale = 0.5 将网络输出 $a_t$ 缩放到默认站立姿态附近 $q^*_t=q_{\text{def}}+0.5\,a_t$，约束搜索空间并防止初期剧烈甩臂。

域随机化范围是不是越宽越好？ADR 怎么解决这个问题？

不是。范围太窄覆盖不到真机参数会直接崩溃；范围太宽时策略为了同时兼容极端摩擦、质量或延迟，只能学出极度保守甚至学不动的动作。ADR（自动域随机化）从窄区间起步，等策略在区间边界达到足够成功率再自动扩宽，在可学性与鲁棒性之间动态平衡。

特权教师–学生蒸馏和非对称 Actor-Critic（AAC）都用了仿真特权信息，两者有什么区别？

教师–学生是两阶段：先让教师策略用特权状态 RL 训到高分，再让只看可部署观测的学生在线 DAgger 模仿教师动作（或像 RMA 那样只回归环境隐变量）。非对称 Actor-Critic 是单阶段：Actor 从一开始就只看可部署观测，只有 Critic 读取特权状态，用来给出更准、低方差的价值与优势估计，无需第二阶段蒸馏。

为什么不能把标准 PPO 直接套在 $\pi_0$ 这类 flow matching VLA 上？$\pi_{\text{RL}}$ 和 RECAP 各怎么解决？

标准 PPO 需要计算采样动作的对数概率 $\log\pi_\theta(a\mid o)$ 来求重要性比值 $\rho_t$，而 flow matching 通过确定性 ODE 生成连续动作块，没有廉价可微的边缘对数似然。$\pi_{\text{RL}}$ 用 Flow-Noise（可学习噪声头）或 Flow-SDE（把 ODE 改写成高斯转移 SDE）把去噪链变成可算步级似然的 MDP；RECAP 则彻底绕开策略梯度，用价值网络标出正负优势后做优势条件化监督学习。
