LLM 强化学习基础

把一次生成看成一条轨迹，奖励只在最后给一次。这一页从策略梯度推到 PPO 和 GRPO，再看 DAPO、RLOO、REINFORCE++、GSPO、CISPO 各改了哪一项，以及大规模训练时真正会出的问题。后面两篇（coding agent、robot-use agent）都建立在这里的记号上。

读完能回答

  • 一条回答的奖励怎样变成每个 token 的梯度？基线为什么能减方差而不引入偏差？
  • PPO 的 clip 在哪几种情况下让梯度变成 0？
  • GRPO 为什么不需要 value model？一组回答全对时会发生什么？
  • 为什么「先对 token 求平均、再对序列求平均」会让错误回答越写越长？
  • 异步 rollout 和训推引擎不一致，为什么都要靠重要性采样修正？

把生成看成一个 MDP

Token 级 MDP：状态 $s_t=(x,y_{<t})$ 是提示加上已生成的 token，动作 $a_t=y_t$ 是下一个 token，转移是确定的拼接 $s_{t+1}=(x,y_{\le t})$，奖励通常只在生成结束时给一次 $R(x,y)$。

记号（全页通用）
符号含义形状
$x$提示（prompt）序列
$y=(y_1,\dots,y_T)$一条回答，也就是一条轨迹；$T=|y|$序列
$s_t=(x,y_{<t})$第 $t$ 步的状态前缀
$\pi_\theta(y_t\mid s_t)$策略 = 语言模型的 next-token 分布$|\mathcal V|$ 维
$R(x,y)$序列奖励：验证器（答案对不对、测试过没过）或奖励模型给出标量
$r_t$第 $t$ 步的即时奖励；稀疏时 $r_t=0\ (t<T)$，$r_T=R$标量
$V^\pi(s)$从 $s$ 出发按 $\pi$ 继续生成，得到的期望奖励标量
$Q^\pi(s,a)$先选 $a$，之后按 $\pi$ 生成的期望奖励标量
$A^\pi(s,a)$优势 $Q^\pi(s,a)-V^\pi(s)$：这个动作比平均好多少标量
$\gamma$折扣因子，LLM 里一般取 $1$标量

整条回答的对数概率是逐 token 对数概率之和，一次 teacher-forcing 前向就能算出全部 $T$ 项，和算 SFT loss 完全一样：

$$\log\pi_\theta(y\mid x)=\sum_{t=1}^{T}\log\pi_\theta(y_t\mid x,y_{<t})$$

转移确定、中间奖励为 0 时，$Q(s_t,a_t)=V(s_{t+1})$，所以一个 token 的优势就是它让「最终答对的概率」涨了多少：$A(s_t,a_t)=V(s_{t+1})-V(s_t)$。

策略梯度

目标是最大化期望奖励 $J(\theta)=\mathbb E_{x\sim\mathcal D}\,\mathbb E_{y\sim\pi_\theta(\cdot\mid x)}[R(x,y)]$。采样这一步不可导，靠 log-derivative trick 绕过去。

  1. 固定 $x$，期望写成对所有回答的求和：

    $$J=\sum_{y}\pi_\theta(y\mid x)\,R(x,y)$$

  2. 求导；$R$ 由验证器给出，和 $\theta$ 无关：

    $$\nabla_\theta J=\sum_y \nabla_\theta\pi_\theta(y\mid x)\,R(x,y)$$

  3. 用 $\nabla\pi=\pi\,\nabla\log\pi$，求和又变回期望，于是可以用采样估计：

    $$\nabla_\theta J=\sum_y\pi_\theta(y\mid x)\,\nabla_\theta\log\pi_\theta(y\mid x)\,R=\mathbb E_{y\sim\pi_\theta}\big[R(x,y)\,\nabla_\theta\log\pi_\theta(y\mid x)\big]$$

  4. 序列对数概率拆成 token 之和：

    $$\nabla_\theta J=\mathbb E\Big[R(x,y)\sum_{t=1}^{T}\nabla_\theta\log\pi_\theta(y_t\mid s_t)\Big]$$

  5. 采 $N$ 条回答做蒙特卡洛估计，这就是 REINFORCE；实现上把 $-R_i\log\pi_\theta(y_i\mid x)$ 当 loss 反传即可：

    $$\hat g=\frac1N\sum_{i=1}^{N}R_i\sum_{t}\nabla_\theta\log\pi_\theta(y_{i,t}\mid s_{i,t})$$

  6. 减去只依赖状态的基线 $b(s_t)$ 不改变期望，因为得分函数的期望为 0：

    $$\mathbb E_{a\sim\pi}\big[b(s_t)\nabla_\theta\log\pi_\theta(a\mid s_t)\big]=b(s_t)\sum_a\nabla_\theta\pi_\theta(a\mid s_t)=b(s_t)\,\nabla_\theta 1=0$$

  7. $y_t$ 影响不到它之前的奖励，$R$ 可换成从 $t$ 起的回报（reward-to-go），其条件期望是 $Q$；再减基线 $V(s_t)$，权重就是优势：

    $$\nabla_\theta J=\mathbb E\Big[\sum_{t}A^\pi(s_t,a_t)\,\nabla_\theta\log\pi_\theta(a_t\mid s_t)\Big]$$
和 SFT 的关系

SFT 的梯度是 $\nabla\log\pi_\theta(y^\star\mid x)$，相当于在示范数据上取 $A\equiv1$ 的策略梯度。RL 在模型自己的样本上用优势加权，优势有正有负：好样本被拉高，差样本被压低。

PPO：重要性比值与 clip

一批 rollout 很贵，希望拆成多个 mini-batch 更新好几步。第一步之后 $\theta\neq\theta_{\text{old}}$，样本就变成了「旧策略」采的，需要重要性采样纠正，同时限制每次走多远。

记号
符号含义形状
$\pi_{\theta_\text{old}}$采样时的策略（行为策略）—
$\rho_t$重要性比值 $\pi_\theta(y_t\mid s_t)/\pi_{\theta_\text{old}}(y_t\mid s_t)$；论文里常写 $r_t(\theta)$，本页用 $\rho$ 以免和奖励混淆标量，每个 token 一个
$\hat A_t$优势估计（PPO 用 GAE，GRPO 用组内归一化）标量，每个 token 一个
$\epsilon$clip 半径，常用 $0.2$标量

  1. 重要性采样：在 $\pi_{\text{old}}$ 的样本上估计 $\pi_\theta$ 下的期望：

    $$\mathbb E_{a\sim\pi_\theta}[f(a)]=\mathbb E_{a\sim\pi_{\text{old}}}\Big[\frac{\pi_\theta(a)}{\pi_{\text{old}}(a)}f(a)\Big]$$

  2. 逐 token 套用，忽略状态分布的变化（这是「近似」之处），得到代理目标：

    $$L(\theta)=\mathbb E_t\big[\rho_t\,\hat A_t\big],\qquad \rho_t=\frac{\pi_\theta(y_t\mid s_t)}{\pi_{\theta_\text{old}}(y_t\mid s_t)}$$

  3. 在 $\theta=\theta_\text{old}$ 处它的梯度正好是策略梯度，因为 $\rho=1$ 且：

    $$\nabla_\theta\rho_t\big|_{\theta_\text{old}}=\frac{\nabla_\theta\pi_\theta(y_t\mid s_t)}{\pi_{\theta_\text{old}}(y_t\mid s_t)}\Big|_{\theta_\text{old}}=\nabla_\theta\log\pi_\theta(y_t\mid s_t)\big|_{\theta_\text{old}}$$

  4. 离 $\theta_\text{old}$ 越远近似越差。PPO 把比值截到 $[1-\epsilon,1+\epsilon]$，再和不截的取较小者（悲观的那个）：

    $$L^{\text{CLIP}}(\theta)=\mathbb E_t\Big[\min\big(\rho_t\hat A_t,\ \operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\,\hat A_t\big)\Big]$$

  5. $\hat A_t>0$：$\rho_t>1+\epsilon$ 时取到常数 $(1+\epsilon)\hat A_t$，梯度为 0，这个 token 的概率已经涨够了；$\rho_t$ 小于 1 时不截，照常往上推。

    $$\hat A_t>0:\quad L_t=\min\big(\rho_t,\,1+\epsilon\big)\hat A_t$$

  6. $\hat A_t<0$：$\rho_t<1-\epsilon$ 时取到常数 $(1-\epsilon)\hat A_t$，梯度为 0；但 $\rho_t$ 很大时不截，惩罚随 $\rho_t$ 线性变大。dual-clip 再加一个下界 $c\hat A_t$（$c>1$）防止这一端发散。

    $$\hat A_t<0:\quad L_t=\max\big(\rho_t,\,1-\epsilon\big)\hat A_t\quad(\text{dual-clip: } \max(L_t,\,c\hat A_t))$$
实现细节

$\rho_t=\exp(\log\pi_\theta-\log\pi_{\text{old}})$。$\log\pi_\text{old}$ 在 rollout 结束后用训练引擎重新前向一遍得到，而不是直接用推理引擎返回的 logprob，原因见实践问题。训练日志里的 clip fraction 是被截断 token 的比例，太大说明每批更新得太猛。

价值模型与 GAE

价值模型（critic） $V_\phi(s_t)$：通常是和策略同规模的 Transformer 加一个标量头，在每个 token 位置输出一个值，回归目标是回报：$L_V=\mathbb E_t\big[(V_\phi(s_t)-\hat R_t)^2\big]$，$\hat R_t=\hat A_t+V_{\phi_\text{old}}(s_t)$。

代价是多一份模型的显存和计算；初始化不准时，早期优势全是噪声（VAPO 因此先在固定策略的样本上预训练 value）。有了 $V$，怎样把稀疏奖励分到每个 token，由 GAE 决定。

  1. TD 残差：一步的「惊喜」：

    $$\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$$

  2. 往前看 $k$ 步的优势估计，中间的 $V$ 两两抵消：

    $$\hat A^{(k)}_t=\sum_{l=0}^{k-1}\gamma^l\delta_{t+l}=-V(s_t)+\sum_{l=0}^{k-1}\gamma^l r_{t+l}+\gamma^kV(s_{t+k})$$

  3. 对所有 $k$ 取指数加权平均，权重 $(1-\lambda)\lambda^{k-1}$，整理后是 $\delta$ 的几何加权和：

    $$\hat A^{\text{GAE}(\gamma,\lambda)}_t=(1-\lambda)\sum_{k\ge1}\lambda^{k-1}\hat A^{(k)}_t=\sum_{l\ge0}(\gamma\lambda)^l\,\delta_{t+l}$$

  4. 两个端点：$\lambda=0$ 只看一步，方差小但完全依赖 $V$ 准不准；$\lambda=1$ 是蒙特卡洛回报减基线，无偏但方差大：

    $$\lambda=0:\ \hat A_t=\delta_t,\qquad \lambda=1:\ \hat A_t=\sum_{l}\gamma^l r_{t+l}-V(s_t)$$

  5. 实现时从序列末尾往前递推，$O(T)$：

    $$\hat A_t=\delta_t+\gamma\lambda\,\hat A_{t+1},\qquad \hat A_{T+1}=0$$

  6. LLM 里 $\gamma=1$，奖励稀疏（若用 KL-in-reward，每步还有 $-\beta\,\mathrm{KL}_t$，见下节）：

    $$\delta_t=V(s_{t+1})-V(s_t)\ (t<T),\qquad \delta_T=R-V(s_T)$$

RLHF 里的 PPO 常用 $\gamma=1,\ \lambda=0.95$。长思维链的回答有上万个 token，VAPO 把两处 $\lambda$ 分开：训练 value 用 $\lambda_\text{critic}=1$，算策略优势用随长度变化的 $\lambda_\text{policy}=1-\frac{1}{\alpha l}$，$\alpha=0.05$。

KL 约束：放进奖励还是放进 loss

为了不让策略离初始模型 $\pi_\text{ref}$（通常是 SFT 模型）太远，有两种加 KL 的位置：

  • KL-in-reward（InstructGPT 式 PPO）：每个 token 的即时奖励减去 $\beta$ 倍的对数比，再经 GAE 进入优势：$r_t=-\beta\log\frac{\pi_\theta(y_t\mid s_t)}{\pi_\text{ref}(y_t\mid s_t)}+\mathbb 1[t=T]\,R$。
  • KL-as-loss（GRPO）：优势只来自 $R$，另在 loss 里加 $-\beta\,\hat D_\text{KL}$，逐 token 用 $k_3$ 估计。

采样 $y\sim\pi_\theta$，记 $u=\log\frac{\pi_\text{ref}(y)}{\pi_\theta(y)}$。$\mathrm{KL}(\pi_\theta\Vert\pi_\text{ref})=\mathbb E[-u]$ 有三种单样本估计（Schulman 2020）：

$$k_1=-u,\qquad k_2=\tfrac12u^2,\qquad k_3=(e^{u}-1)-u$$

$k_1$ 无偏但会取负、方差大；$k_2$ 有偏、方差小；$k_3$ 无偏（因为 $\mathbb E[e^u]=1$）且恒 $\ge0$。

  1. 把估计量当 loss 直接求导（样本不回传梯度）得到的未必是 KL 的梯度。记 $\nabla\log\pi_\theta$ 为得分函数，$\nabla_\theta u=-\nabla\log\pi_\theta(y)$：

    $$\nabla k_1=\nabla\log\pi_\theta,\quad \nabla k_2=-u\,\nabla\log\pi_\theta,\quad \nabla k_3=(1-e^{u})\nabla\log\pi_\theta$$

  2. 对 $y\sim\pi_\theta$ 取期望，用 $\mathbb E[\nabla\log\pi_\theta]=0$ 和 $\mathbb E_{\pi_\theta}[e^u f]=\mathbb E_{\pi_\text{ref}}[f]$：

    $$\mathbb E\nabla k_1=0,\quad \mathbb E\nabla k_2=\nabla\mathrm{KL}(\pi_\theta\Vert\pi_\text{ref}),\quad \mathbb E\nabla k_3=-\mathbb E_{\pi_\text{ref}}[\nabla\log\pi_\theta]=\nabla\mathrm{KL}(\pi_\text{ref}\Vert\pi_\theta)$$

所以 $k_1$ 当 loss 期望梯度为 0，$k_2$ 给的是 reverse KL 的梯度，GRPO 用的 $k_3$ 给的是 forward KL 的梯度（REINFORCE++ 论文据此改用 $k_2$）。另外，可验证奖励的推理 RL 常常干脆令 $\beta=0$（DAPO 去掉了 KL 项）：模型本来就要走得离初始化很远，而且省掉 $\pi_\text{ref}$ 的前向。

GRPO：用组内平均代替 critic

GRPO（Group Relative Policy Optimization，DeepSeekMath 2024 提出，DeepSeek-R1 沿用）：同一个提示采 $G$ 条回答，用组内奖励的均值和标准差把每条回答的奖励变成优势，不要 value model。

记号
符号含义形状
$G$每个提示的采样数（组大小），常见 8–64整数
$y_i,\ R_i$第 $i$ 条回答及其奖励序列，标量
$\hat A_{i,t}$第 $i$ 条回答第 $t$ 个 token 的优势；GRPO 里同一条回答的所有 token 相同标量
$\rho_{i,t}$$\pi_\theta(y_{i,t}\mid s_{i,t})/\pi_{\theta_\text{old}}(y_{i,t}\mid s_{i,t})$标量
$$\mathcal J_\text{GRPO}=\mathbb E\Bigg[\frac1G\sum_{i=1}^{G}\frac1{|y_i|}\sum_{t=1}^{|y_i|}\Big\{\min\big(\rho_{i,t}\hat A_{i,t},\ \operatorname{clip}(\rho_{i,t},1-\epsilon,1+\epsilon)\hat A_{i,t}\big)-\beta\,\hat D_\text{KL}\Big\}\Bigg],\qquad \hat A_{i,t}=\frac{R_i-\operatorname{mean}(R_{1..G})}{\operatorname{std}(R_{1..G})}$$

  1. 奖励是 0/1、组内答对比例为 $\hat p$ 时，均值是 $\hat p$，标准差是：

    $$\operatorname{std}=\sqrt{\hat p(1-\hat p)}$$

  2. 于是答对的回答和答错的回答的优势分别是：

    $$\hat A^+=\sqrt{\frac{1-\hat p}{\hat p}},\qquad \hat A^-=-\sqrt{\frac{\hat p}{1-\hat p}}$$

  3. 难题（$\hat p$ 小）里偶尔答对的那条拿到很大的正优势；全对或全错（$\hat p\in\{0,1\}$）时分子为 0，这一组没有梯度。真实正确率为 $p$ 时，一组落空的概率是：

    $$P(\text{零信号})=p^G+(1-p)^G$$
易错

GRPO 给一条回答里的所有 token 同一个优势，信用分配比 GAE 粗：一条答对的长推理里写错又改对的那几步，也一起被奖励。这对单轮数学题问题不大，到多轮 agent 里就是主要矛盾之一，见 coding agent 的多轮目标。

动手：同一个策略，REINFORCE 和 GRPO 怎么推

一个只有一步的「LLM」：对提示 17+25=? 输出 5 个候选答案之一，策略是 5 个 logit 上的 softmax。每一步从同一提示采 $G$ 个答案，左边用不带基线的 REINFORCE（权重 $R_i$），右边用 GRPO（权重 $\hat A_i$）。只更新一步、$\rho\equiv1$，所以这里 GRPO 就是「组内归一化的 REINFORCE」。

损失怎么聚合：长度偏置

同一个 batch 里回答长短不一。每个 token 的 loss 项 $\ell_{i,t}$（clip 后的 $\rho\hat A$）怎样加起来，决定了长回答和短回答各占多少梯度。

三种聚合（verl 里的 loss_agg_mode）
名称公式每个 token 的权重
seq-mean-token-mean$\frac1G\sum_i\frac1{|y_i|}\sum_t\ell_{i,t}$（原始 GRPO）$\frac{1}{G\,|y_i|}$，随本条长度变小
token-mean$\frac{1}{\sum_i|y_i|}\sum_i\sum_t\ell_{i,t}$（DAPO）$\frac{1}{\sum_j|y_j|}$，所有 token 一样
seq-mean-token-sum-norm$\frac{1}{G\,L_\text{max}}\sum_i\sum_t\ell_{i,t}$（Dr. GRPO）$\frac{1}{G\,L_\text{max}}$，常数，不随 batch 变

Dr. GRPO（Liu et al. 2025）指出原始 GRPO 有两处偏置并都去掉：一是 $1/|y_i|$：答错（$\hat A<0$）时越长的回答每个 token 被罚得越少，于是错误回答越写越长；答对时越短的回答每个 token 奖励越大。二是除以组内 std：方差小（太易或太难）的题被放大权重。

变体：各改了哪一项

DAPO（2025.03）

ByteDance Seed 与清华 AIR，Qwen2.5-32B 基座，AIME 2024 得 50 分（avg@32），训练步数是 DeepSeek-R1-Zero-Qwen-32B（47 分）的一半。在 GRPO 上改了四处并去掉 KL 项，$G=16$：

  • Clip-Higher：$\epsilon_\text{low}=0.2,\ \epsilon_\text{high}=0.28$，给低概率 token 上涨空间，缓解熵塌缩。
  • Dynamic Sampling：多采一些，丢掉全对、全错的组，直到 batch 填满，约束 $0<|\{y_i\text{ 答对}\}|<G$。
  • Token-level loss：上一节的 token-mean。
  • Overlong reward shaping：被截断的样本不算 loss（overlong filtering），或加软惩罚。期望长度 16,384，缓冲 $L_\text{cache}=4{,}096$，硬上限 $L_\text{max}=20{,}480$：
$$R_\text{length}(y)=\begin{cases}0, & |y|\le L_\text{max}-L_\text{cache}\\[2pt] \dfrac{(L_\text{max}-L_\text{cache})-|y|}{L_\text{cache}}, & L_\text{max}-L_\text{cache}<|y|\le L_\text{max}\\[6pt] -1, & |y|>L_\text{max}\end{cases}$$

RLOO（2024）

Ahmadian et al.（Cohere）把整条回答当一个动作，基线用同组其余样本的均值，不需要 critic；论文的结论是 RLHF 场景下 PPO 的许多部件并不必要。基线不含 $y_i$ 自己，所以严格无偏：

$$\hat A_i=R_i-\frac{1}{G-1}\sum_{j\ne i}R_j=\frac{G}{G-1}\big(R_i-\bar R\big)$$

REINFORCE++（2025.01）

Hu et al.：KL 用 $k_1$ 逐 token 折进奖励，优势是从 $t$ 起的累计值；归一化放在整个全局 batch 上，而不是每个提示的小组内，避免小组 std 带来的偏置。变体 REINFORCE++-baseline 先减组内均值，再用全局 batch 的 std 归一化，KL 改用 $k_2$ 作 loss。

$$A_{t}=R-\beta\sum_{i=t}^{T}\mathrm{KL}_i,\qquad A^\text{norm}_t=\frac{A_t-\operatorname{mean}_\text{batch}(A)}{\operatorname{std}_\text{batch}(A)}$$

GSPO（2025.07）

Qwen 团队：比值和 clip 都放到序列级。比值按长度开 $1/|y_i|$ 次方，同一条回答的所有 token 用同一个权重。论文报告这去掉了 MoE 模型 RL 对 Routing Replay 的依赖（GRPO 下一次更新后约 10% 的被激活专家会变），用于新版 Qwen3 模型。因为比值是几何平均，clip 范围很小（实验里左右分别 $3\times10^{-4}$、$4\times10^{-4}$）。

$$s_i(\theta)=\Big(\frac{\pi_\theta(y_i\mid x)}{\pi_{\theta_\text{old}}(y_i\mid x)}\Big)^{\frac1{|y_i|}}=\exp\Big(\frac1{|y_i|}\sum_{t}\log\rho_{i,t}\Big),\qquad \mathcal J=\mathbb E\Big[\frac1G\sum_i\min\big(s_i\hat A_i,\ \operatorname{clip}(s_i,1-\epsilon,1+\epsilon)\hat A_i\big)\Big]$$

CISPO（2025.06）

MiniMax-M1：PPO 的 clip 会让 token 失去梯度，论文观察到 However、Recheck、Wait、Aha 这类低概率的「反思」token 在第一次 on-policy 更新后就被 clip 掉。CISPO 只截断重要性权重并 stop-gradient，所有 token 都保留梯度；在 Qwen2.5-32B 的对照实验里比 DAPO 快一倍（同样效果所需步数减半）。

$$\mathcal J_\text{CISPO}=\mathbb E\Big[\frac{1}{\sum_i|y_i|}\sum_i\sum_t\operatorname{sg}\big(\hat\rho_{i,t}\big)\,\hat A_{i,t}\,\log\pi_\theta(y_{i,t}\mid s_{i,t})\Big],\qquad \hat\rho_{i,t}=\operatorname{clip}(\rho_{i,t},1-\epsilon^{IS}_\text{low},1+\epsilon^{IS}_\text{high})$$

大规模训练里的实际问题

异步 rollout 与陈旧度

同步训练：用 $\theta_k$ 采一整批，等最长的那条生成完，再训练。长尾很长时 GPU 大量空转（coding agent 一页有时间线图）。异步训练让推理端一直生成，训练端拿到的样本来自 $\theta_{k-s}$，$s$ 叫陈旧度（staleness）。这时行为策略不再是 $\pi_{\theta_\text{old}}$，比值必须相对真正采样的策略计算。

AReaL（Fu et al. 2025）用解耦的 PPO 目标：行为策略 $\pi_\text{behav}$ 负责重要性修正，近端策略 $\pi_\text{prox}$（每次更新前的参数）负责 trust region；最大陈旧度 $\eta$ 默认代码任务 4、数学 8，报告相对同步系统最多 2.77× 的训练加速：

$$J(\theta)=\mathbb E_{a_t\sim\pi_\text{behav}}\Big[\sum_t\frac{\pi_\text{prox}(a_t\mid s_t)}{\pi_\text{behav}(a_t\mid s_t)}\min\big(u_t\hat A_t,\ \operatorname{clip}(u_t,1-\epsilon,1+\epsilon)\hat A_t\big)\Big],\qquad u_t=\frac{\pi_\theta(a_t\mid s_t)}{\pi_\text{prox}(a_t\mid s_t)}$$

训推不一致与截断重要性采样

rollout 用 vLLM / SGLang，训练用 FSDP / Megatron。同一组权重，两边的 kernel、精度、归约顺序、MoE 路由不同，给出的 token 概率也不同，于是「on-policy」训练其实是 off-policy 的。Yao et al.（2025.08，Your Efficient RL Framework Secretly Brings You Off-Policy RL Training）提出 TIS：在梯度上乘一个截断的修正权重，$C$ 是截断阈值：

$$\nabla_\theta J\approx\mathbb E_{y\sim\pi^\text{infer}_{\theta_\text{old}}}\Big[\min\Big(\frac{\pi^\text{train}_{\theta_\text{old}}(y_t\mid s_t)}{\pi^\text{infer}_{\theta_\text{old}}(y_t\mid s_t)},\,C\Big)\,\nabla_\theta\min\big(\rho_t\hat A_t,\ \operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t\big)\Big]$$

截断用一点偏差换有界方差。异步陈旧度和训推不一致是同一类问题：样本分布和被优化的分布不一样，都靠重要性比值修正。

熵塌缩

训练中策略熵很快下降，模型不再探索，奖励随之停滞。Cui et al.（2025）拟合出 $R=-a\,e^{H}+b$：熵耗尽（$H=0$）时性能上限是 $-a+b$；熵的变化由「动作概率」和「logit 变化」的协方差驱动，后者正比于优势，所以高概率又高优势的 token 不断吃掉熵。对策：Clip-Higher、对高协方差 token 做 Clip-Cov / KL-Cov、熵奖励。

Reward hacking

策略优化的是验证器给的分数，不是出题人的意图：格式规则有漏洞会被钻，LLM 当裁判时会学会讨好裁判，长度和得分相关时回答会变长。验证器越严格、越难绕过，RL 越可靠。代码任务里奖励是「测试是否通过」，相应的防护见 coding agent 的奖励设计。

自测

为什么减去基线 $b(s_t)$ 不改变梯度的期望？$b$ 能不能依赖当前动作 $a_t$？

因为 $\mathbb E_{a\sim\pi}[\nabla\log\pi(a\mid s)]=\nabla\sum_a\pi(a\mid s)=0$，常数（或只依赖 $s$ 的量）提出来后乘的是 0。若 $b$ 依赖 $a_t$ 就提不出来，一般会引入偏差。RLOO 的基线用的是其他样本的奖励，不含 $y_i$ 自己，所以无偏。

$\hat A<0$ 且 $\rho=2.5$，$\epsilon=0.2$，PPO 这个 token 还有梯度吗？

有。负优势时只截 $\rho<1-\epsilon$ 的一侧，$\rho$ 大时目标是 $\rho\hat A$，梯度为 $\hat A$。这正是 dual-clip 想限制的情况：加下界 $c\hat A$ 后，$\rho>c$ 时梯度为 0。

GAE 的 $\lambda=1$ 和 $\lambda=0$ 分别对应什么？critic 很差时该往哪边调？

$\lambda=1$ 是蒙特卡洛回报减 $V(s_t)$，对梯度无偏、方差大；$\lambda=0$ 是一步 TD 残差 $\delta_t$，方差小但偏差等于 critic 的误差。critic 差时往 1 调，这也是 VAPO 训练 value 时用 $\lambda=1$ 的原因。

GRPO 一组 8 条全部答对，这组对梯度有什么贡献？

没有（KL 项除外）。均值等于每条的奖励，优势全为 0。正确率为 $p$ 时这样白采的概率是 $p^8+(1-p)^8$，DAPO 的动态采样把这类组丢掉再补采。

为什么 seq-mean-token-mean 会让错误回答变长？

每条回答的总权重固定为 $|\hat A_i|/G$，摊到 $|y_i|$ 个 token 上；错误回答越长，每个 token 受的惩罚越小，长的错误写法相对「安全」。token-mean 或除以常数可以消除这个偏置。

GRPO 的 KL 用 $k_3$ 当 loss，梯度对应哪一个 KL？

$\mathbb E\nabla k_3=-\mathbb E_{\pi_\text{ref}}[\nabla\log\pi_\theta]$，是 forward KL $\mathrm{KL}(\pi_\text{ref}\Vert\pi_\theta)$ 的梯度。要得到 reverse KL 的梯度，应该用 $k_2$ 当 loss，或把 $k_1$ 放进奖励。

权重刚同步完，推理引擎和训练引擎用的是同一组参数，为什么还需要 TIS？

两边实现不同（kernel、精度、归约顺序、MoE 路由），对同一 token 给出的概率不同，采样分布 $\pi^\text{infer}$ 不等于训练时算梯度的 $\pi^\text{train}$。TIS 乘上截断后的 $\pi^\text{train}/\pi^\text{infer}$ 来修正。
