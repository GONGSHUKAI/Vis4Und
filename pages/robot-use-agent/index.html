Robot-Use Agent 的训练

让一个推理 VLM 像 computer-use agent 操作电脑那样操作机器人：每轮看相机画面和机械臂状态，写一段思维链，输出下一步末端位姿。这一页讲动作接口，以及 2026 年 11 月的两条训练路线：PEAR 在仿真里只用任务成功信号做 RL，nanoAstra 把真机示教改写成语义步骤做 SFT。

Robot-use agent 是什么

Robot-use agent（RUA）：一个多模态推理模型直接当机器人策略用。每一轮它看观测（相机图像 + 机械臂状态），在思维链里推理，再用文本写出动作；动作由逆运动学和控制器执行，执行结果成为下一轮的观测，之前所有轮都留在上下文里。

它和 computer-use agent 一一对应：截图 ↔ 相机画面，click(812, 431) ↔ 末端位姿 JSON，操作系统 ↔ IK + 控制器。PEAR 强调的是没有 harness：没有感知工具、抓取或运动规划器、技能库，找物体、估距离、发现动作没做到位，全靠模型自己看图。

三种用 VLM 控制机器人的方式

方式模型输出谁负责几何与执行例子
VLA动作头输出连续动作块（关节或末端，几十步）模型本身；控制器高频跟踪π0.5、OpenVLA、GR00T
带 harness 的 agent工具调用或代码：调用检测、抓取、运动规划、技能库工具和规划器ORA、ASPIRE、Harness VLA、PyRUA-Lean
Robot-use agent文本动作：下一个末端位姿（PEAR），或参数化原语序列（nanoAstra）模型自己从图像里估；IK + 控制器只负责走到目标PEAR、nanoAstra；也用于评测 GPT-6 Astra 这类闭源模型

据 PEAR 摘要，到 2026 年 11 月，强的 robot-use 表现只出现在闭源前沿模型（GPT-6 Astra、Claude Fable 5.2）上，开源权重模型差得多。两篇论文都想回答：一个开源 VLM 怎么训成 RUA。

模型拿到的只有量的名字和数值，没有任何关于“x 是哪个方向”的隐含信息，所以 ENVIRONMENT 段要用文字写清楚，例如 RoboDojo：原点在两臂基座中点，+x 向前、+y 向左、+z 向上；头部相机里图像上方是 +x、左方是 +y；夹爪初始朝前，roll +1.57 变成朝下。模型要自己把图像方向换算成机器人坐标系。

PEAR：仿真里的 Robot-Use RL

Robot-Use RL（RURL）：在仿真机器人任务上，以“仿真器报告成功”为唯一奖励，对推理模型做多轮 RL；不用示教、不做 SFT。PEAR（Post-training Engine for Agentic Robotics）是实现它的训练框架，建在 verl 和 LMCache 上。基座是 Qwen3.8-27B。

记号（沿用 PEAR 论文；和 RL 基础 一页的对应关系见右列）
符号含义备注
$p$系统提示：协议 + ENVIRONMENT + 任务指令相当于 $x$
$o_t,\ y_t$第 $t$ 轮的观测（状态 JSON + 图像）、模型的回复（思维链 + 动作）$t=1,\dots,T$
$\tau=(o_1,y_1,\dots,o_T,y_T)$一集（episode）一条轨迹
$h_t=(p,o_1,y_1,\dots,o_t)$第 $t$ 轮开始时的上下文
$y_{i,t}^{k},\ c_{i,t}^{k}$第 $i$ 集第 $t$ 轮回复的第 $k$ 个 token，及其上下文 $(h_{i,t},y_{i,t}^{<k})$相当于 $y_t,\ s_t$
$\pi_\theta,\ \mu$正在训练的策略；实际生成这一集的策略$\mu$ 相当于 $\pi_{\theta_\text{old}}$
$R(\tau)\in\{0,1\}$这一集结束时仿真器是否报告成功唯一奖励
$G,\ \hat A_i$组大小（同任务、同初始状态的 $G$ 集，PEAR 取 8）；第 $i$ 集的优势
$N$一个 batch 里所有生成 token 的个数token-mean 的分母

目标和梯度

  1. 目标是最大化期望成功率：

    $$J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}\big[R(\tau)\big]$$

  2. 一集的概率里，只有模型生成的 token 依赖 $\theta$；观测 $o_t$ 来自仿真器，求导时是常数：

    $$\begin{aligned}\log P_\theta(\tau)=&\sum_{t=1}^{T}\sum_{k}\log\pi_\theta\big(y_t^{k}\mid c_t^{k}\big)\\&+\underbrace{\sum_t\log P(o_{t+1}\mid h_t,y_t)}_{\text{与 }\theta\text{ 无关}}\end{aligned}$$

  3. 用对数导数技巧得到策略梯度。所以观测 token（图像、状态）不进损失，所有轮的思维链和动作 token 都进：

    $$\nabla_\theta J=\mathbb{E}_\tau\Big[R(\tau)\sum_{t,k}\nabla_\theta\log\pi_\theta\big(y_t^{k}\mid c_t^{k}\big)\Big]$$

  4. 同一任务、同一初始状态采 $G$ 集，用组内均值做 baseline、组内标准差归一化（GRPO）：

    $$\hat A_i=\frac{R(\tau_i)-\operatorname{mean}_j R(\tau_j)}{\operatorname{std}_j R(\tau_j)+\epsilon}$$

  5. 每个生成 token 都拿这一集的 $\hat A_i$，不管它是推理还是动作、在第几轮；按 batch 内生成 token 总数 $N$ 平均（token-mean），不做 PPO 裁剪，不加 KL 惩罚和熵奖励：

    $$\begin{gathered}g=\frac1N\sum_i\hat A_i\sum_{t,k}\Big[\nabla_\theta\log\pi_\theta\big(y_{i,t}^{k}\mid c_{i,t}^{k}\big)-\bar s_{i,t}^{k}\Big]\\ \bar s_{i,t}^{k}=\mathbb{E}_{v\sim\mu(\cdot\mid c_{i,t}^{k})}\big[\nabla_\theta\log\pi_\theta(v\mid c_{i,t}^{k})\big]\end{gathered}$$

    第一项是带组均值 baseline 的 REINFORCE；减去的 $\bar s$ 是 score centering，下面单独讲。

二值奖励下的组过滤

奖励只有 0/1 时，一组 8 集要么全败、要么全成，$\hat A$ 全为 0，这一组不贡献梯度。PEAR 照 DAPO 的做法把这样的组丢掉、重新采样，直到凑满 128 个有效组。设当前任务的单集成功率为 $q$，一组被保留的概率是

$$\begin{gathered}f(q)=1-q^{G}-(1-q)^{G}\\ \text{凑满 128 组平均要采}\ \ \frac{128}{f(q)}\ \text{组}\end{gathered}$$

保留下来的组里，若 $k$ 集成功（$\bar q=k/G$，标准差取总体标准差 $\sqrt{\bar q(1-\bar q)}$），成功集和失败集的优势分别是

$$\hat A_{+}=\sqrt{\frac{1-\bar q}{\bar q}},\qquad \hat A_{-}=-\sqrt{\frac{\bar q}{1-\bar q}}$$

成功越稀有，那一次成功被放大得越多：8 集里只成 1 次时 $\hat A_+=2.65$、$\hat A_-=-0.38$。

全异步训练与 score centering

PEAR 的 rollout 和参数更新完全异步，生成一集的策略 $\mu$ 比正在训练的 $\pi_\theta$ 落后一到两个版本。在策略（$\mu=\pi_\theta$）时，score 的期望恒为零：

$$\begin{aligned}\mathbb{E}_{v\sim\pi_\theta}\big[\nabla_\theta\log\pi_\theta(v)\big]&=\sum_v\pi_\theta(v)\frac{\nabla_\theta\pi_\theta(v)}{\pi_\theta(v)}\\&=\nabla_\theta\sum_v\pi_\theta(v)=\nabla_\theta 1=0\end{aligned}$$

token 从 $\mu$ 采时，这个期望不再为零，即使某个位置上选哪个 token 和成败毫无关系，梯度也会有一个系统性的漂移。Score centering 直接减掉它在 $\mu$ 下的期望。看 logits 最清楚：

  1. 设这一位置的 logits 为 $z$，$\pi=\operatorname{softmax}(z)$，对 logits 的 score 是

    $$\nabla_z\log\pi(y)=\mathbf e_y-\pi$$

  2. 它在 $\mu$ 下的期望：

    $$\mathbb{E}_{v\sim\mu}\big[\mathbf e_v-\pi\big]=\mu-\pi$$

  3. 减掉后，每个 token 对 logits 的梯度变成

    $$\begin{gathered}(\mathbf e_y-\pi)-(\mu-\pi)=\mathbf e_y-\mu\\ \mathbb{E}_{y\sim\mu}\big[\mathbf e_y-\mu\big]=0\end{gathered}$$

    也就是用采样时的分布 $\mu$ 代替当前分布 $\pi$ 做中心化。不修正时，这个位置的期望梯度是 $\hat A(\mu-\pi)$：$\hat A>0$ 把 $\pi$ 往 $\mu$ 拉，$\hat A<0$ 往远推（这三步是本页的推导，不是论文原文）。

PEAR 只用这一项修正分布差异，不用截断重要性采样（TIS，见 RL 基础 · 实践问题）。

课程：先训有信号的任务

基座在 LIBERO 的 Spatial / Object / Goal 上约 2%，在 LIBERO-Long 上 0.4%，在大多数 RoboDojo 任务上几乎为 0。PEAR 的办法是先训已经偶尔能成功的任务，靠迁移把其他任务的成功率抬起来，再把它们加进训练：

PEAR：结果

  • 从近零起步也能学：1.6% → 74.4%，接近 GPT-6 Astra / GPT-6.1 Sol 的 max 档，但仍低于对每个任务做示教 SFT 的 π0.5（96.9%）。
  • 差别在换任务：LIBERO-Pro 的“同一场景换一个任务”，π0.5 从 96.9% 掉到 0.75%（照旧做训练时那个任务），PEAR 模型从 74.4% 掉到 57.4%。只改措辞或物体外观时 π0.5 仍领先。
  • 迁移：只在 LIBERO 上训，换到 RoboDojo 的双臂 ARX、换仿真器，general_pickup 10.7% → 39.9%；再在 RoboDojo 上训 115 步后，真机双臂 YAM 30 次成功 18 次（基座 0 次），没有用过任何真机数据。
  • 代价是慢：xhigh 平均每轮思考 3.23k token；改用 low（0.86k token/轮）成功率降到 21.9%。GB300 上 747 token/s 时，一轮 xhigh 思考约 4.3 s。

论文自述的局限

  • 规模小：两个仿真器、两个 RoboDojo 任务、27B 基座，受 GPU 限制没有继续放大。
  • 没做 SFT：缺高质量同分布数据，也担心损伤通用能力；作者认为机器人数据应进预训练 / 中训练，而不是对已后训练的模型做 SFT。
  • 慢：RL 不惩罚长度，个别轮思维链到 32k token，单步动作超过半分钟。
  • 依赖 prompt：基座对所控制的本体了解少，难任务要在 prompt 里把本体和任务写得很细。
  • 还不能可靠地输出动作块，只输出下一个位姿，精度部分取决于控制器，复杂动作要拆成很多轮。完整 RoboDojo 基准上，540 集里有 370 集因为 256k 上下文用完而失败。

nanoAstra：语义步骤与 CP-SFT

nanoAstra：把 5,310 小时真机和手持夹爪示教切成“语义步骤”，让 VLM 用普通文本写出当前进度和接下来的几步参数化原语，没有单独的动作头。训练是一轮全参 SFT（基座 Qwen3.5-9B），同时混入通用 VQA 数据以保住原有能力。作者的动机是复现 GPT-6 Astra 那种直接控制机器人的泛化能力。

语义步骤：在决策点切开示教

VLA 学的是按固定频率采样的动作块，同一个行为会因为控制频率、速度、局部修正而变成不同的序列。nanoAstra 在行为决策点切开轨迹：夹爪开合、停顿、急转弯、手腕大幅旋转；子任务边界一定是切点。每段变成一个步骤，用平移、旋转、夹爪、等待四类原语表示，配一句描述局部目标的进度文本（由 Qwen3.5-122B-A10B 给子任务视频片段打标）。

CP-SFT：用系统提示圈出一块输出空间

一个专门的机器人系统提示 $c_r$ 写明本体、坐标约定、动作词表和回复格式。给定输入 $x$（图像、状态、指令、交互历史），模型输出进度 $g$ 和步骤 $A$，结构化回复空间是

$$\mathcal Y_r(c_r)=\big\{\operatorname{Serialize}(g,A)\ \big|\ g\in\mathcal G,\ A\in\mathcal A(c_r)\big\}$$

所有机器人监督都落在带 $c_r$ 的这块空间里；不带 $c_r$ 时同一个模型照常用自然语言回答。作者的意图是让适配集中在机器人上下文里，少改动其他情况下的输出分布（“软约束”，论文没有给出隔离程度的定量分析）。

数字的 Wasserstein 损失

交叉熵只看正确数字的概率：目标是 5 时，把概率放在 4 上和放在 9 上损失一样。动作里全是数字，nanoAstra 在 CE 之外加了一个改造过的 Wasserstein Number Token Loss（原方法见 Zausinger et al.）。

记号
符号含义形状
$\nu,\ y_\nu$回复里的一个数字，及它的目标数值标量
$D_\nu$$\nu$ 的各个数位集合
$d_j,\ 10^{e_j}$第 $j$ 位的目标数字和它的位值（$12.5$ 的三位 $e_j=1,0,-1$）$d_j\in\{0,\dots,9\}$
$T_\nu,\ w_j$$T_\nu=\sum_{j}10^{e_j}$；位权 $w_j=10^{e_j}/T_\nu$标量
$\tilde p_j(v)$第 $j$ 位上，softmax 只在 10 个数字 token 上重新归一化后的分布10 维
$z_\text{true},\ z_\text{flip}$正确符号 token 与符号相反 token 的 logit标量
$\lambda$数字损失的权重，取 0.3标量

  1. 两个一维离散分布 $P,Q$ 的 Wasserstein-1 距离等于累积分布之差的面积。目标是单点分布 $\delta_{d}$ 时，把 $\tilde p$ 的每一份质量从 $v$ 搬到 $d$，代价就是距离 $|v-d|$：

    $$W_1(\tilde p,\delta_d)=\sum_{v=0}^{9}\tilde p(v)\,|v-d|$$

  2. 按位值加权求和，高位错一格的代价是低位的 10 倍：

    $$\ell^{\text{digit}}_\nu=\sum_{j\in D_\nu}w_j\sum_{v=0}^{9}\tilde p_j(v)\,|v-d_j|$$

  3. 数位损失看不到符号错误（$+3.0$ 和 $-3.0$ 的数位一样），所以单独监督符号；数值越大，符号错的代价越大：

    $$\ell^{\text{sign}}_\nu=\frac{2|y_\nu|}{T_\nu}\,\sigma\big(z_\text{flip}-z_\text{true}\big)$$

    其中 $\sigma(z_\text{flip}-z_\text{true})=\dfrac{e^{z_\text{flip}}}{e^{z_\text{flip}}+e^{z_\text{true}}}$，是两个符号 token 之间错号所占的比例；没有显式符号的数字这一项为 0。

  4. 对样本 $s$ 中的所有数字 $N_s$ 取平均，再和 CE 相加；$\mathcal B$ 是一个优化步里跨 GPU、跨梯度累积的全部原始样本，保证打包（packing）后每个样本权重相同：

    $$\begin{gathered}\ell^{\text{num}}_s=\frac{1}{|N_s|}\sum_{\nu\in N_s}\big(\ell^{\text{digit}}_\nu+\ell^{\text{sign}}_\nu\big)\\ \mathcal L=\frac{1}{|\mathcal B|}\sum_{s\in\mathcal B}\big(\ell^{\text{CE}}_s+\lambda\,\ell^{\text{num}}_s\big)\end{gathered}$$

训练设置

Qwen3.5-9B 初始化，ms-swift 实现，56 张 H20 训一个 epoch；每步 56 个数据包（平均约 188 个原始样本）；AdamW，峰值学习率 $10^{-5}$，cosine 调度，warmup 1%，weight decay 0.1；最长 8,192 token，每张图 392 个视觉 token；bf16，DeepSpeed ZeRO-2；全参微调。

解读

两篇的基座、规模、评测集都不同，表里的数字不能直接比高低。可以比较的是取舍：nanoAstra 用大量真实示教换来“不思考也能直接出动作”和低延迟，但 SFT 损失了一些通用能力；PEAR 不碰示教，用 RL 和长思维链换来换任务时的鲁棒性和几乎无损的通用能力，代价是每一步都慢。PEAR 引用的 “RL’s Razor”（在新任务上做 RL 比 SFT 遗忘少）和这两组通用能力数字的方向一致，但这不是受控对比。

还没解决的问题

以下是本页的解读，不是论文的结论。

  • 延迟：PEAR 每步几秒，nanoAstra 靠不思考和流式把推理藏起来。在 RL 里加长度奖励（PEAR 留作未来工作）或把思考蒸馏短，是否会掉成功率，还没有数据。
  • 动作粒度：单个位姿太细（轮数多、上下文爆），直线原语太粗（铰接物体做不了）。介于两者之间的是让模型可靠地写出动作块或带曲线的原语。
  • 奖励：只用 0/1 成功信号，需要课程才能起步；稀疏任务（如完整 RoboDojo）大部分仍学不到。部分完成的进度分（RoboLab 的 Score 这类）能否当奖励，未验证。
  • 上下文：一集近 10 万 token，长任务会用完上下文。PEAR 的代码库后来加了通过 Claude Code 服务模型、上下文满时压缩对话的部署方式，但训练时仍是整集一条序列。
  • 两条路线能否合并：nanoAstra 式的真实示教放进中训练、再做 PEAR 式仿真 RL，正是 PEAR 作者在局限里提议的数据用法，目前没有人报告结果。

自测

PEAR 的动作是绝对位姿还是增量？单位是什么？

增量。状态 JSON 给每个量的当前绝对值，动作 JSON 给每个量的变化量，长度用 cm、角度用 rad，不动的量写 0。执行到所有目标到达且静止（或被挡住）才返回下一个观测。

为什么第一阶段不训 LIBERO-Long？

基座在 LIBERO-Long 上成功率 0.4%，8 集一组几乎全败，组过滤后几乎没有可用的组，RL 没信号。先训另外三套，LIBERO-Long 靠迁移升到 39.0% 后再加入；同时它也成了干净的迁移测试。

单集成功率 2%、组大小 8 时，大约多少比例的组能留下？

$f=1-0.98^8-0.02^8\approx0.149$，约 15%。凑满 128 组平均要采约 860 组。

Score centering 在 logits 层面等价于什么？为什么需要它？

把每个 token 的 logits 梯度从 $\mathbf e_y-\pi$ 换成 $\mathbf e_y-\mu$，即用采样时的分布做中心化。全异步时 $\mu\ne\pi$，不修正的话即使 token 与回报无关，期望梯度也有 $\hat A(\mu-\pi)$ 的漂移；修正后期望为 0。

π0.5 在 LIBERO 上 96.9%，在 LIBERO-Pro “同场景换任务”上只有 0.75%，说明什么？

示教模仿学到的是“这个场景做这个动作”。指令换成另一个任务时，它照旧做训练过的任务。PEAR 模型在这里是 57.4%，掉得少，因为它是读指令和画面再推理动作。只改措辞或外观时 π0.5 仍领先，因为原动作依然正确。

nanoAstra 为什么要加数字的 Wasserstein 损失？符号项解决什么？

交叉熵只看正确数字的概率，错成相邻数字和错得很远代价一样；Wasserstein 项按 $|v-d|$ 计代价，并按位值加权，让高位更重要。数位损失看不出 $+3.0$ 和 $-3.0$ 的区别，符号项单独惩罚错号，权重随数值大小增大。

I/M = 0.64 意味着什么？为什么 RTX 4090 上流式执行效果差？

H20 上一次推理 1.69 s，产生的动作要执行 2.66 s，推理比动作快，下一次回复可以在剩下两步执行完之前写出新步骤，机器人几乎不用等。RTX 4090 上推理 3.89 s，比动作长（I/M=1.36），新步骤写出的速度跟不上执行，流式也会出现等待。
