Vis4Und.

做机器人学习研究要补的预备知识，每个专题一页：先给定义，再用可以拖动、可以逐步播放的图把机制演示出来，公式先列记号再推导。

4 个方向 · 15 个专题

(1)

机器人学

Robotics

动作用什么坐标表示，关节空间和末端空间怎么换算，相机怎样把三维世界投到像素上。

  • (i)旋转与位姿表示Rotations & Poses旋转矩阵、欧拉角、轴角、四元数、6D 表示和齐次变换：定义、互相换算、插值，以及网络该输出哪一种。
  • (ii)机器人的运动空间Action Spaces, FK & IK关节空间与末端空间、绝对动作与增量动作、正运动学、雅可比与逆运动学；VLA 的动作到底在哪个空间里。
  • (iii)相机模型与标定Camera Models & Calibration针孔模型、内参与畸变、外参、各家坐标系约定、张正友标定、手眼标定和深度反投影。
(2)

3D 视觉与图形学

3D Vision & Graphics

三维场景用什么数据结构表示，怎样边走边建图和定位，以及前馈式的 3D 重建与生成模型。

  • (i)3D 表征3D Representations深度图、点云、体素、网格、SDF、NeRF 和 3D 高斯：各自存什么、怎么互相转换、什么任务该用哪种。
  • (ii)SLAMSimultaneous Localization and Mapping边走边定位边建图：前端里程计、后端因子图与光束法平差、回环检测，以及学习式和高斯式 SLAM 的近年进展。
  • (iii)3D 基础模型3D Foundation Models前馈式重建（DUSt3R、VGGT 一系）、单目几何估计，以及 3D 物体与场景生成。
(3)

Agentic RL

Agentic RL

用强化学习训练多轮行动的智能体：先讲 LLM 上的策略梯度，再看 coding agent 和直接操控机器人的 robot-use agent。

  • (i)LLM 强化学习基础Policy Gradients for LLMs从策略梯度到 PPO、GRPO 及其变体：把一次生成看成一条轨迹，奖励怎么变成每个 token 的梯度。
  • (ii)Coding Agent 的训练Training Coding Agents多轮工具调用的轨迹、可执行环境与测试奖励、SFT 冷启动加多轮 RL，以及几套经典开源实现。
  • (iii)Robot-Use Agent 的训练Training Robot-Use Agents让推理模型像操作电脑一样直接操作机器人：动作接口、仿真里只用成功信号的 RL（PEAR），和把动作写成语义步骤的 SFT（nanoAstra）。
(4)

分布式训练

Distributed Training

模型一张卡放不下、一张卡算不完时怎么训：显存与算力的账、数值精度、集合通信、优化器、FlashAttention，以及 DP / FSDP / TP / SP / PP / CP / EP 等并行怎么切、怎么组合。

  • (i)训练的显存与算力账GPU Memory & FLOPsGPU 的存储层级与 roofline，一步训练要多少 FLOPs、MFU 怎么算，参数 / 梯度 / 优化器状态 / 激活各占多少显存，以及重计算和梯度累积。
  • (ii)数值精度与混合精度Number Formats & Mixed PrecisionFP32 / TF32 / FP16 / BF16 / FP8 / MXFP8 / MXFP4 / NVFP4 的位布局与取值范围，混合精度训练、loss scaling、FP8 与块缩放、随机舍入。
  • (iii)集合通信Collective Communicationbroadcast、reduce、all-reduce、all-gather、reduce-scatter、all-to-all 的语义与通信量，ring 与 tree 算法的 α-β 代价，NVLink / InfiniBand 拓扑与 NCCL。
  • (iv)优化器：从 Adam 到 MuonOptimizers: Adam to Muon动量 SGD、Adam、AdamW 的更新与状态，学习率调度与梯度裁剪，Muon 的 Newton–Schulz 正交化及其在大模型上的用法。
  • (v)FlashAttention 系列FlashAttention 1–4标准 attention 的显存读写瓶颈，online softmax 与分块，FlashAttention 1 / 2 / 3 / 4 各改了什么，以及 Flash-Decoding 和变长、掩码变体。
  • (vi)并行策略Parallelism: DP, FSDP, TP, SP, PP, CP, EP数据并行与 ZeRO / FSDP / HSDP，张量并行与序列并行，流水线的 GPipe / 1F1B / 交错 / Zero Bubble / DualPipe，上下文并行（Ring Attention、Ulysses），MoE 的专家并行与 ETP，以及多维组合与配置估算。
