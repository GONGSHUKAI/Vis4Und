机器人学

Robotics

动作用什么坐标表示，关节空间和末端空间怎么换算，相机怎样把三维世界投到像素上。

  • 补充旋转与位姿表示补充Rotations & Poses旋转矩阵、欧拉角、轴角、四元数、6D 表示和齐次变换：定义、互相换算、插值，以及网络该输出哪一种。
  • (i)机器人的运动空间Action Spaces, FK & IK关节空间与末端空间、绝对动作与增量动作、正运动学、雅可比与逆运动学；VLA 的动作到底在哪个空间里。
  • (ii)相机模型与标定Camera Models & Calibration针孔模型、内参与畸变、外参、各家坐标系约定、张正友标定、手眼标定和深度反投影。
(2)

3D 视觉与图形学

3D Vision & Graphics

三维场景用什么数据结构表示，怎样边走边建图和定位，以及前馈式的 3D 重建与生成模型。

  • (i)3D 表征3D Representations深度图、点云、体素、网格、SDF、NeRF 和 3D 高斯：各自存什么、怎么互相转换、什么任务该用哪种。
  • (ii)SLAMSimultaneous Localization and Mapping边走边定位边建图：前端里程计、后端因子图与光束法平差、回环检测，以及学习式和高斯式 SLAM 的近年进展。
  • (iii)3D 基础模型3D Foundation Models前馈式重建（DUSt3R、VGGT 一系）、单目几何估计，以及 3D 物体与场景生成。
(3)

Agentic RL

Agentic RL

用强化学习训练多轮行动的智能体：先讲 LLM 上的策略梯度，再看 coding agent 和直接操控机器人的 robot-use agent。

  • 补充LLM 强化学习基础补充Policy Gradients for LLMs从策略梯度到 PPO、GRPO 及其变体：把一次生成看成一条轨迹，奖励怎么变成每个 token 的梯度。
  • (i)Coding Agent 的训练Training Coding Agents多轮工具调用的轨迹、可执行环境与测试奖励、SFT 冷启动加多轮 RL，以及几套经典开源实现。
  • (ii)Robot-Use Agent 的训练Training Robot-Use Agents让推理模型像操作电脑一样直接操作机器人：动作接口、仿真里只用成功信号的 RL（PEAR），和把动作写成语义步骤的 SFT（nanoAstra）。
